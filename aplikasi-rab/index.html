Panduan

Cara memakai Aplikasi RAB, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Estimator untuk menyusun RAB, rincian, harga satuan, dan revisi; atau sebagai Manajer untuk menyetujui atau menolak revisi RAB dan melihat laporan.
  2. Di tab RAB, tambah proyek baru (otomatis mendapat RAB versi 1 Draf). Klik Detail untuk melihat versi RAB, rincian versi berlaku, dan realisasi — di sana juga bisa mencatat realisasi baru per rincian pekerjaan.
  3. Di tab Rincian, pilih proyek dan versi RAB, lalu tambah rincian pekerjaan dari daftar harga satuan (nama, kategori, satuan, dan harga terisi otomatis) atau pekerjaan custom. Subtotal = volume × harga satuan. Rincian hanya bisa diubah pada versi berstatus Draf.
  4. Di tab Harga Satuan, kelola daftar harga satuan pekerjaan dan material. Harga satuan yang sudah dipakai di rincian tidak bisa dihapus.
  5. Di tab Revisi, buat revisi baru dari versi terakhir (rincian disalin otomatis), lalu manajer Setujui atau Tolak. Versi yang disetujui menjadi yang berlaku; versi berlaku lama berubah menjadi Diganti.
  6. Di tab Laporan, bandingkan anggaran dengan realisasi per periode, per proyek, dan per kategori. Gunakan Ekspor CSV dan Backup JSON untuk arsip. Data contoh bisa dikembalikan dari kartu Data contoh di bawah.
  7. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123 (semua akses, termasuk kelola pengguna); Estimator — estimator / estimator123 (menyusun RAB, rincian, harga satuan, revisi; tidak bisa menyetujui RAB atau kelola pengguna); Manajer — manajer / manajer123 (menyetujui/menolak revisi RAB, melihat laporan dan perbandingan anggaran vs realisasi). Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh PM Oyen (3 proyek, 4 versi RAB, 35 rincian pekerjaan, 16 harga satuan, 7 realisasi; total anggaran versi berlaku Rp731.475.000; total realisasi Rp417.850.000). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Harga satuan dalam aplikasi ini adalah harga contoh, bukan harga pasar resmi — sesuaikan dengan harga di daerah dan waktu pengerjaan Anda. Aplikasi ini bukan sistem akuntansi dan bukan payment gateway (pembayaran dicatat manual). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh tim di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
