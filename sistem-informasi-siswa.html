      Panduan Penggunaan

      Cara memakai setiap tab di aplikasi Student Information System (SIS), langkah demi langkah.

      1

      Tab Data Siswa — mengelola database siswa

      1) Ketuk tombol Tambah Siswa, isi formulir (NIS, nama, tempat/tanggal lahir, jenis kelamin, alamat, kelas, tahun masuk, status, nomor HP), lalu ketuk Simpan. 2) Untuk mengubah data, ketuk Ubah pada baris siswa. 3) Untuk menghapus, ketuk Hapus lalu konfirmasi. 4) Gunakan kotak pencarian dan saringan kelas/status untuk menemukan siswa. 5) Ketuk Ekspor CSV untuk mengunduh seluruh data siswa sebagai file CSV.

      2

      Tab Akademik — riwayat nilai & prestasi

      1) Pilih nama siswa pada daftar pilihan di bagian atas. 2) Riwayat nilai per semester (Matematika, Bahasa Indonesia, IPA, IPS, Bahasa Inggris), rata-rata, keterangan naik kelas, dan prestasi tampil otomatis. 3) Ketuk Tambah Catatan untuk menambah semester baru, atau Ubah pada baris catatan untuk memperbaiki nilai, keterangan, dan prestasi.

      3

      Tab Orang Tua — data ayah, ibu, dan wali

      1) Ketik nama siswa di kotak pencarian untuk menemukan data orang tuanya. 2) Ketuk Ubah untuk mengisi atau memperbaiki nama ayah, nama ibu, pekerjaan, nomor HP, dan alamat. 3) Ketuk Hapus untuk mengosongkan data orang tua seorang siswa. 4) Bila data belum ada, ketuk Tambah Data pada baris siswa tersebut.

      4

      Tab Dokumen — kelengkapan berkas

      1) Cari siswa lewat kotak pencarian atau saring berdasarkan status. 2) Ketuk chip dokumen (Akta Kelahiran, Kartu Keluarga, Ijazah, Foto, Rapor) untuk menandai dokumen sudah dikumpulkan; ketuk lagi untuk membatalkan. 3) Status otomatis berubah menjadi Lengkap bila kelima dokumen sudah terkumpul, dan batang kemajuan menunjukkan jumlah dokumen yang masuk.

      5

      Tab Pencarian — temukan siswa secepatnya

      1) Ketik sebagian nama atau NIS siswa. 2) Hasil muncul langsung saat mengetik, menampilkan kelas, status, wali kelas, dan nomor HP orang tua — berguna saat perlu menghubungi orang tua dengan cepat.

      6

      Tab Laporan — ringkasan sekolah

      1) Lihat jumlah siswa per kelas dan per status (Aktif, Lulus, Pindah). 2) Periksa daftar siswa yang dokumennya belum lengkap untuk ditindaklanjuti. 3) Lihat daftar siswa baru tahun ini. 4) Ketuk Ekspor Ringkasan ke CSV untuk mengunduh laporan sebagai file CSV.

      7

      Tentang data di aplikasi ini

      Seluruh data tersimpan sementara di memori halaman selama aplikasi dibuka. Menambah, mengubah, dan menghapus data berlaku selama sesi ini; saat aplikasi ditutup dan dibuka lagi, data kembali ke data contoh awal.

      Garansi

      Perbaikan bug/error gratis untuk fitur yang tercantum di panduan ini, selama masa garansi:

      • Beli Sekali: Pemula 30 hari / Profesional 60 hari / Bisnis 90 hari.
      • Berlangganan: garansi + dukungan selama langganan aktif.

      Cara klaim: hubungi via WhatsApp dengan mengirim video/screenshot bug yang ditemukan, agar bisa diperiksa dan diperbaiki.

      Tidak termasuk garansi: permintaan fitur baru, perubahan desain/data, kerusakan karena pembeli mengedit file sendiri, dan layanan pihak ketiga (hosting/domain pembeli).
      Versi demo v1 — data contoh hanya berlaku selama aplikasi dibuka. Data akan kembali ke data contoh saat aplikasi ditutup dan dibuka lagi.
