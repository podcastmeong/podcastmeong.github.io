Panduan Penggunaan

Cara memakai Aplikasi Pengiriman, harga, dan garansi.

Cara memakai

  1. Tambahkan Sopir di tab Sopir: nama, nomor HP, nomor SIM, kendaraan, dan nomor polisi.
  2. Di tab Jadwal, buat jadwal pengiriman: nomor surat jalan, tanggal, pelanggan dan alamat tujuan, barang dan jumlahnya, lalu pilih sopir yang ditugaskan.
  3. Saat sopir berangkat, ubah status di tab Status (atau tombol cepat di tab Jadwal) menjadi Dalam Perjalanan.
  4. Setelah barang sampai, catat di tab Bukti Terima: nama penerima, tanggal dan jam diterima, serta kondisi barang. Status pengiriman otomatis menjadi Terkirim.
  5. Bila pengiriman gagal (misalnya toko tutup atau alamat salah), ubah status menjadi Gagal lalu Jadwalkan Ulang bila perlu dikirim lagi.
  6. Di tab Riwayat, cari pengiriman lama berdasarkan nomor surat jalan, pelanggan, atau barang.
  7. Di tab Laporan, pilih bulan dan lihat rekap pengiriman serta kinerja tiap sopir — bisa dicetak atau disimpan sebagai PDF.
  8. Masuk dengan akun Anda (Admin / Gudang / Kurir) — akun demo: admin / admin123, gudang / gudang123, kurir / kurir123. Sesi berlaku selama tab masih terbuka.
  9. Pilih Cabang aktif di tab Jadwal — jadwal, sopir, bukti, dan statistik mengikuti cabang itu; laporan menampilkan ringkasan semua cabang.
  10. Aksi sensitif (hapus jadwal, hapus sopir, hapus bukti terima) tidak langsung jalan — diajukan ke tab Persetujuan dan baru berlaku bila disetujui Admin/Gudang. Semua tercatat di tab Audit Log.
  11. Semua data tersimpan otomatis di perangkat ini (IndexedDB + enkripsi) setiap kali ada perubahan. Cadangkan berkala dengan tombol Backup JSON di tab Laporan.

Catatan penting (jujur)

Aplikasi ini berupa satu file HTML dan bekerja offline. Data sopir, jadwal, status, dan bukti terima hanya tersimpan di perangkat ini — sekarang di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256). Jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Data tidak tersinkron ke perangkat lain dan tidak ada backup cloud otomatis — pakai tombol Backup JSON di tab Laporan secara berkala. Aplikasi ini BUKAN .exe native — dibuka lewat browser di laptop atau HP. Aplikasi ini tidak memiliki pelacakan GPS sungguhan — posisi sopir tidak dilacak; status pengiriman diubah manual oleh admin/sopir. Untuk pemakaian bersama oleh banyak staf di perangkat berbeda (multi-user lintas perangkat) dan pelacakan GPS, dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
