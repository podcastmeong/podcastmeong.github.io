Kelola Pengguna

Hanya admin yang melihat bagian ini. Admin bisa menambah pengguna, mengubah peran, menonaktifkan pengguna, dan mengganti kata sandi pengguna. Pengguna yang dinonaktifkan tidak bisa masuk. Gudang adalah petugas gudang: bisa mengelola spare part, supplier, pembelian, pemakaian, dan opname — tapi tidak bisa membuka kasir dan laporan. Kasir adalah operator toko: bisa menjual dan melihat laporan — tapi tidak bisa mengelola pengguna, supplier, atau pembelian.

Panduan

Cara memakai Aplikasi Stok Spare Part, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Gudang untuk spare part, supplier, pembelian, pemakaian, dan opname; atau sebagai Kasir untuk penjualan dan laporan.
  2. Di tab Spare Part, kelola data barang: kode, nama, kategori, merek, harga beli dan jual, stok, stok minimum, dan lokasi rak. Klik Riwayat untuk melihat semua pergerakan stok barang itu.
  3. Di tab Supplier, kelola data pemasok: nama, nomor HP, alamat, dan kategori barang yang dipasok.
  4. Di tab Stok Masuk, catat pembelian dari supplier: barang, jumlah, dan harga beli. Stok bertambah otomatis.
  5. Di tab Pemakaian, catat stok yang dipakai bengkel (bukan dijual). Stok berkurang otomatis; bila stok tidak cukup, pemakaian ditolak.
  6. Di tab Opname, hitung stok fisik di rak dan cocokkan dengan stok tercatat. Bila berbeda, stok disesuaikan otomatis dan selisihnya tercatat dengan alasan.
  7. Di tab Riwayat Stok, lihat semua pergerakan: masuk, penjualan, pemakaian, dan opname — bisa disaring per barang dan per jenis.
  8. Di tab Kasir, jual spare part: tambah barang ke keranjang, isi uang dibayar untuk melihat kembalian, lalu simpan. Stok berkurang otomatis dan penjualan masuk omzet.
  9. Di tab Laporan, lihat transaksi, omzet, laba, pembelian, dan barang terlaris per periode. Gunakan Ekspor CSV untuk mengunduh laporan, dan Backup JSON untuk menyimpan seluruh data; Pulihkan Backup mengembalikan data dari file backup.
  10. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Gudang — gudang / gudang123; Kasir — kasir / kasir123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Oyen Spare Part (17 spare part mobil dan motor, 6 supplier, 8 pembelian, 3 pemakaian bengkel, 3 opname, dan 7 penjualan dalam 7 hari terakhir). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini mencatat stok spare part, supplier, pembelian, pemakaian, opname, penjualan, omzet, dan laba dari selisih harga jual dan harga beli — bukan sistem akuntansi (tidak menghitung gaji, sewa toko, listrik, atau biaya lain selain harga beli barang) dan bukan payment gateway (kasir mencatat pembayaran Tunai / QRIS / Transfer secara manual). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh gudang dan kasir di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
