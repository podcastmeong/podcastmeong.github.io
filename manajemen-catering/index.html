Panduan

Cara memakai Manajemen Catering, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; atau sebagai Kasir (operator catering) untuk mengelola pesanan, paket, pelanggan, jadwal, biaya, dan laporan.
  2. Di tab Pesanan, buat pesanan baru: nama acara, pelanggan, paket, jumlah porsi, tanggal, jam kirim, dan alamat. Total harga, biaya bahan, dan laba langsung terlihat sebelum disimpan. Ubah status pesanan dengan tombol Lanjut Status: Baru → Disiapkan → Dikirim → Selesai.
  3. Di tab Paket Menu, kelola paket catering: pilih isi menu dari 12 menu Warung Kopi Oyen dan tentukan harga per porsi. Biaya bahan dan margin dihitung otomatis dari resep. Paket yang masih dipakai pesanan tidak bisa dihapus.
  4. Di tab Jadwal, lihat pengiriman per tanggal dan rencana 7 hari ke depan — supaya dapur tahu berapa porsi yang harus dimasak tiap hari.
  5. Di tab Pelanggan, kelola data pelanggan acara. Pelanggan yang masih punya pesanan tidak bisa dihapus.
  6. Di tab Biaya, lihat margin tiap paket dan tiap menu, serta gunakan Kalkulator Pesanan untuk menghitung laba satu acara sebelum menerima pesanan.
  7. Di tab Laporan, lihat omzet, biaya bahan, dan laba per periode, serta perbandingan tiap paket.
  8. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Data contoh

Aplikasi ini memakai data contoh Katering Oyen (3 paket menu, 12 menu acuan, 4 pelanggan, 6 pesanan contoh dalam 7 hari terakhir). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini menghitung biaya bahan dari resep dan mencatat pesanan, jadwal, dan pelanggan catering — bukan sistem kasir dengan pembayaran dan bukan sistem akuntansi (tidak menghitung gaji, sewa, listrik, gas, atau biaya lain selain biaya bahan). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh dapur dan kasir di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut. Aplikasi ini cocok dipasangkan dengan Restaurant POS, Kitchen Display System, Aplikasi Pemesanan Makanan, Manajemen Meja, Manajemen Resep & Bahan Baku, dan Manajemen Franchise Makanan kami.
