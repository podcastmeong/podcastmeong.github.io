Jasa Game — 2 Jenis

Bisnis game kami ada 2 jenis yang berbeda. Yang pertama, game dibuatkan khusus untuk customer. Yang kedua, game jadi dijual supaya bisa langsung dimainkan. Harga keduanya beda jauh — jangan dicampur.

Jenis A

Jasa Pembuatan Game

Customer memesan, kami buatkan game custom sesuai permintaan: jenis game, jumlah level, karakter, platform. Harga dihitung per proyek — makin rumit gamenya, makin mahal.

Kisaran: Rp500 ribu s.d. miliaran per proyek (Menurut ChatGPT)

Jenis B

Jual Game Buat Dimainkan

Game sudah jadi, dibeli sebagai file lalu langsung dimainkan di browser atau HP. Tanpa pesan custom, tanpa menunggu dibuatkan — harganya jauh lebih murah.

Kisaran: Rp149.000 – Rp499.000 per file (Harga usulan kami)

Yang diterima customer

  1. Game yang sudah bisa dimainkan.
  2. File instalasi atau akses game.
  3. Source code sesuai kesepakatan.
  4. Desain karakter dan aset.
  5. Dokumentasi penggunaan.
  6. Pengujian dan perbaikan bug sesuai kontrak.
  7. Hak penggunaan atau kepemilikan sesuai perjanjian.
  8. Garansi pemeliharaan dengan jangka waktu yang jelas.
Catatan jujur: angka di bagian A ini adalah harga jasa pembuatan game custom (proyek per pesanan, menurut ChatGPT) — bukan harga file game jadi di bagian B. Karena itu harganya jutaan sampai miliaran, sementara file game jadi kami hanya ratusan ribu.
