Jasa Game — 2 Jenis

Bisnis game kami ada 2 jenis yang berbeda. Yang pertama, game dibuatkan khusus untuk customer. Yang kedua, game jadi dijual supaya bisa langsung dimainkan. Harga keduanya beda jauh — jangan dicampur.

Jenis A

Jasa Pembuatan Game

Customer memesan, kami buatkan game custom sesuai permintaan: jenis game, jumlah level, karakter, platform. Harga dihitung per proyek — makin rumit gamenya, makin mahal.

Kisaran: Rp2.500.000 – Rp20.000.000 per proyek

Jenis B

Jual Game Buat Dimainkan

Game sudah jadi, dibeli sebagai file lalu langsung dimainkan di browser atau HP. Tanpa pesan custom, tanpa menunggu dibuatkan — harganya jauh lebih murah.

Kisaran: Rp19.900 – Rp99.900 per file (Harga diputuskan Cipta)

A — Jasa Pembuatan Game (Custom)

Game dibuatkan khusus untuk customer yang memesan. Harga jasa pembuatan game custom kami ada di 3 paket di bawah ini.

Harga di bawah adalah harga paket jasa pembuatan custom kami, bukan harga file game jadi.

Harga paket di atas adalah harga penawaran jasa kami. Multiplayer, server, lisensi, biaya store, dan pemeliharaan dapat menambah biaya.

Yang diterima customer

  1. Game yang sudah bisa dimainkan.
  2. File instalasi atau akses game.
  3. Source code sesuai kesepakatan.
  4. Desain karakter dan aset.
  5. Dokumentasi penggunaan.
  6. Pengujian dan perbaikan bug sesuai kontrak.
  7. Hak penggunaan atau kepemilikan sesuai perjanjian.
  8. Garansi pemeliharaan dengan jangka waktu yang jelas.
Catatan jujur: angka di bagian A ini adalah harga jasa pembuatan game custom (proyek per pesanan) — bukan harga file game jadi di bagian B. Karena itu harganya jutaan rupiah, sementara file game jadi kami hanya puluhan ribu.

Kenapa jauh lebih murah dari jasa pembuatan? File game jadi hanya dibeli sekali lalu dimainkan — tidak ada pengerjaan custom, tidak ada source code lengkap, tidak ada revisi per customer. Jasa pembuatan (bagian A) membuat game baru dari nol sesuai pesanan, karena itu harganya per proyek jutaan rupiah.

Faktor yang perlu dihitung sebelum menentukan harga

  1. Biaya pembuatan & waktu pengembangan.
  2. Biaya platform & komisi penjualan.
  3. Biaya pemasaran & promosi.
  4. Target pemain & daya beli pasar.
  5. Jumlah konten, durasi permainan, dan kualitas.
  6. Biaya dukungan, pembaruan, dan pemeliharaan.
