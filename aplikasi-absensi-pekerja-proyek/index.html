Cara memakai Aplikasi Absensi Pekerja Proyek.

Cara Memakai

  1. Masuk dengan salah satu akun demo di bawah.
  2. Mandor mencatat Absensi setiap hari: pilih pekerja, tanggal, status (Hadir / Terlambat / Izin / Sakit / Alpa), jam masuk dan pulang.
  3. Cek Rekap untuk melihat kehadiran tiap pekerja dan persentasenya.
  4. Keuangan membuka Upah untuk menghitung upah harian: Hadir dan Terlambat dibayar penuh, Izin / Sakit / Alpa tidak dibayar.
  5. Rekap di Laporan dan ekspor CSV atau bagikan ringkasannya via WhatsApp.

Peran Pengguna

  • Admin — semua akses, termasuk tambah pekerja, kelola pengguna, dan hapus data.
  • Mandor — mencatat absensi harian dan melihat data pekerja proyeknya (PRY-002). Tidak bisa tambah pekerja, kelola pengguna, atau membuka Laporan.
  • Keuangan — menghitung upah harian, rekap, dan laporan. Tidak bisa mencatat absensi atau tambah pekerja.

Batasan yang Jujur

  • Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.
  • Aplikasi ini bukan sistem multi-perangkat dan bukan payment gateway. Tidak ada sinkronisasi antar-perangkat.
  • Upah dihitung dari status absensi saja; tidak ada potongan denda keterlambatan atau lembur — sesuaikan dengan aturan perusahaan Anda.
  • Angka dan nama di sini adalah contoh demo, bukan harga resmi atau data pekerja sungguhan.
