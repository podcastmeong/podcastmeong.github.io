Pembukuan khusus perusahaan distributor: kas masuk & keluar, biaya operasional, hutang supplier, piutang pelanggan, laporan laba rugi, dan laporan keuntungan — semua dalam satu file. Multi-cabang, tiga peran pengguna, alur persetujuan, dan penyimpanan IndexedDB terenkripsi — tetap offline di perangkat ini.

Panduan Penggunaan

Cara memakai Aplikasi Akuntansi Distributor, harga, dan garansi.

Cara memakai

  1. Di tab Kas, catat setiap uang masuk dan keluar: penjualan tunai, pembelian barang tunai, pelunasan piutang, dan bayar hutang.
  2. Di tab Biaya, catat biaya operasional: gaji, sewa gudang, BBM, listrik, pengiriman, dan ATK.
  3. Bila membeli barang secara kredit, catat di tab Hutang: supplier, jumlah, dan jatuh tempo. Bayar lewat tombol Catat Pembayaran — kas keluar tercatat otomatis.
  4. Bila menjual barang secara kredit, catat di tab Piutang: pelanggan, jumlah, dan jatuh tempo. Terima pelunasan lewat tombol Catat Pelunasan — kas masuk tercatat otomatis.
  5. Di tab Laba Rugi, pilih bulan dan lihat laba bersih: pendapatan − pembelian barang − biaya operasional.
  6. Di tab Laporan, lihat rekap bulanan lengkap beserta sisa hutang per supplier dan sisa piutang per pelanggan — bisa dicetak atau disimpan sebagai PDF.
  7. Masuk dengan akun Anda (Admin / Manajer / Akuntan) — akun demo: admin / admin123, manajer / manajer123, akuntan / akuntan123. Sesi berlaku selama tab masih terbuka.
  8. Pilih Cabang aktif di tab Kas — kas, biaya, hutang, piutang, dan statistik mengikuti cabang itu; laporan menampilkan ringkasan semua cabang.
  9. Aksi sensitif (hapus transaksi kas/biaya/hutang/piutang, dan kas keluar Rp5.000.000 atau lebih) tidak langsung jalan — diajukan ke tab Persetujuan dan baru berlaku bila disetujui Admin/Manajer. Semua tercatat di tab Audit Log.
  10. Semua data tersimpan otomatis di perangkat ini (IndexedDB + enkripsi) setiap kali ada perubahan. Cadangkan berkala dengan tombol Backup JSON di tab Laporan.

Cara baca angka (supaya konsisten)

  • Pendapatan = penjualan tunai (Kas masuk kategori Penjualan) + penjualan kredit (piutang baru pada bulan itu).
  • Pembelian barang = pembelian tunai (Kas keluar kategori Pembelian Barang) + pembelian kredit (hutang baru pada bulan itu).
  • Laba kotor = pendapatan − pembelian barang. Laba bersih = laba kotor − biaya operasional.
  • Pelunasan piutang dan bayar hutang tidak masuk laba rugi — itu pelunasan, bukan pendapatan atau biaya — tetapi keduanya mengubah saldo kas dan sisa hutang/piutang.
  • Selisih kas (kas masuk − kas keluar) dihitung dari transaksi kas pada bulan itu saja, tanpa saldo awal — bukan saldo rekening bank.

Catatan penting (jujur)

Aplikasi ini berupa satu file HTML dan bekerja offline. Data kas, biaya, hutang, piutang, dan laporan hanya tersimpan di perangkat ini — sekarang di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256). Jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Data tidak tersinkron ke perangkat lain dan tidak ada backup cloud otomatis — pakai tombol Backup JSON di tab Laporan secara berkala. Aplikasi ini BUKAN .exe native — dibuka lewat browser di laptop atau HP. Aplikasi ini tidak terhubung ke bank sungguhan: semua transaksi diinput manual. Aplikasi ini punya tiga peran pengguna (Admin, Manajer, Akuntan) di perangkat ini. Untuk pemakaian bersama oleh banyak staf di perangkat berbeda (multi-user lintas perangkat) dan penyimpanan permanen di server dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
