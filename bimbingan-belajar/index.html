Panduan Penggunaan

Ikuti langkah-langkah berikut untuk memakai setiap tab. Semua perubahan data langsung tampil dan terhitung ulang otomatis.

Tab Siswa

  1. Isi formulir Tambah Siswa: nama, kelas sekolah, program bimbel, nomor HP orang tua, dan tanggal bergabung.
  2. Klik Simpan Siswa — siswa langsung muncul di daftar.
  3. Gunakan kolom pencarian untuk mencari berdasarkan nama siswa atau nama program.
  4. Klik Ubah untuk memperbaiki data (formulir terisi otomatis), atau Hapus untuk menghapus siswa beserta data terkaitnya.

Tab Jadwal

  1. Isi formulir Tambah Sesi Les: hari, jam mulai–selesai, program, tutor, dan ruangan.
  2. Klik Simpan Sesi untuk menambahkan sesi ke jadwal mingguan.
  3. Gunakan filter hari untuk melihat sesi pada hari tertentu saja.
  4. Klik Ubah atau Hapus pada baris sesi untuk mengelola jadwal.

Tab Absensi

  1. Pilih tanggal dan sesi les, lalu klik Muat Daftar Siswa.
  2. Daftar siswa yang tampil adalah siswa pada program sesi tersebut. Tandai tiap siswa: Hadir, Izin, Sakit, atau Alpa.
  3. Klik Simpan Absensi. Untuk mengubah, buka tanggal dan sesi yang sama, perbaiki tanda, lalu simpan lagi.
  4. Rekap kehadiran per siswa di bawahnya terhitung otomatis dari semua catatan absensi.

Tab Pembayaran

  1. Pilih siswa, bulan tagihan, jumlah, dan status (Lunas / Belum Lunas), lalu klik Simpan Pembayaran.
  2. Gunakan filter status untuk melihat tagihan yang belum lunas saja.
  3. Panel hijau di atas daftar menampilkan total pemasukan dari pembayaran Lunas pada bulan berjalan.
  4. Klik Ubah untuk melunasi tagihan (ganti status menjadi Lunas) atau memperbaiki jumlah.

Tab Tryout

  1. Pilih siswa, mata pelajaran, skor (0–100), dan tanggal tryout, lalu klik Simpan Nilai.
  2. Tabel Peringkat Tryout mengurutkan siswa berdasarkan rata-rata skor dan terhitung ulang setiap ada nilai baru.
  3. Gunakan filter mata pelajaran pada riwayat nilai untuk melihat nilai per mata pelajaran.

Tab Laporan

  1. Laporan terhitung otomatis: siswa aktif per program, pemasukan per bulan, tingkat kehadiran per program, dan rata-rata tryout per program.
  2. Klik Unduh Rekap CSV untuk mengunduh rekap lengkap (per program dan per siswa) sebagai file CSV yang bisa dibuka di Excel atau Google Sheets.

Cara klaim: hubungi via WhatsApp dan kirimkan video atau screenshot bug/error yang ditemukan, beserta keterangan singkat kapan masalahnya muncul.

  • Permintaan fitur baru di luar fitur yang dijual.
  • Perubahan desain atau perubahan data.
  • Kerusakan akibat pembeli mengedit file aplikasi sendiri.
  • Layanan pihak ketiga, termasuk hosting dan domain milik pembeli.
