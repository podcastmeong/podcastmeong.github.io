Panduan

Cara memakai Manajemen Franchise Makanan, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur cabang, menu standar, dan pengguna; atau sebagai Kasir (operator cabang) untuk mencatat penjualan dan mengatur stok cabang.
  2. Di tab Cabang, kelola data cabang franchise (nama, alamat, penanggung jawab, telepon, status aktif). Cabang yang dihapus ikut menghapus penjualan dan stoknya — hati-hati.
  3. Di tab Menu Standar, kelola menu dan harga yang berlaku sama di semua cabang. Mengubah harga di sini langsung mengubah harga di semua cabang. Hanya admin yang bisa mengubah menu standar.
  4. Di tab Penjualan, pilih cabang, tambahkan item dari menu standar, lalu simpan. Total dihitung otomatis dari harga standar.
  5. Di tab Stok, pilih cabang untuk melihat stok bahannya. Tombol + Stok mencatat pembelian bahan; − Stok mencatat pemakaian di luar penjualan (misal bahan rusak atau terbuang). Bahan di bawah stok minimum ditandai peringatan.
  6. Di tab Laporan, bandingkan omzet, transaksi, rata-rata per transaksi, dan menu terlaris tiap cabang dalam periode yang dipilih.
  7. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Kasir — kasir / kasir123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh franchise Warung Kopi Oyen (4 cabang, 12 menu standar, 16 bahan baku, 14 penjualan contoh dalam 7 hari terakhir). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini mengelola data cabang, menu standar, penjualan, dan stok bahan per cabang — bukan sistem kasir dengan pembayaran dan bukan sistem akuntansi. Semua data cabang tersimpan di perangkat yang membuka aplikasi ini (satu perangkat) dan tidak tersinkron antar-cabang secara otomatis.
