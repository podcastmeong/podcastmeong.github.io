Panduan Penggunaan

Cara memakai Aplikasi Piutang, harga, dan garansi.

Cara memakai

  1. Tambahkan Pelanggan di tab Pelanggan: nama toko, kontak, nomor HP WhatsApp, dan tempo standar (misalnya 14 hari).
  2. Setiap ada penjualan tempo, catat di tab Piutang: pilih pelanggan, isi keterangan/faktur dan total — tanggal jatuh tempo dihitung otomatis dari tempo.
  3. Di tab Jatuh Tempo, lihat piutang yang sudah atau segera jatuh tempo. Kirim pengingat lewat tombol WhatsApp atau Salin Pengingat, lalu tekan Sudah Diingatkan.
  4. Saat pelanggan membayar, catat di tab Pembayaran: pilih piutang, isi jumlah dan metode (Tunai / Transfer / QRIS). Boleh dicicil — bila jumlah sama dengan sisa, piutang otomatis Lunas.
  5. Di tab Laporan, pilih bulan untuk melihat piutang baru, pembayaran diterima, dan umur piutang (berapa hari lewat jatuh tempo) per kelompok. Laporan bisa dicetak atau diunduh sebagai CSV.
  6. Semua data tersimpan otomatis di perangkat ini setiap kali ada perubahan.

Catatan penting (jujur)

Aplikasi ini berupa satu file HTML dan bekerja offline. Data pelanggan, piutang, dan pembayaran hanya tersimpan di perangkat ini (localStorage browser perangkat yang membuka aplikasi) — data tersimpan PER PERANGKAT dan tidak tersinkron ke perangkat lain. Aplikasi ini BUKAN .exe native — dibuka lewat browser di laptop atau HP. Aplikasi ini tidak memproses pembayaran online sungguhan — pembayaran dicatat manual setelah uang diterima (tunai/transfer/QRIS di luar aplikasi). Untuk pemakaian bersama oleh banyak staf di perangkat berbeda (multi-user lintas perangkat) atau penyimpanan permanen di server dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
