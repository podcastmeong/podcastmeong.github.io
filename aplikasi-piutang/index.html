Panduan Penggunaan

Cara memakai Aplikasi Piutang, harga, dan garansi.

Cara memakai

  1. Masuk dulu dengan nama pengguna dan kata sandi Anda (akun demo ada di layar masuk). Sesi berlaku selama tab peramban masih terbuka — memuat ulang tidak meminta masuk lagi, menutup tab meminta masuk kembali.
  2. Pilih cabang aktif di tab Piutang — piutang, pembayaran, pelanggan, dan statistik mengikuti cabang itu.
  3. Tambahkan Pelanggan di tab Pelanggan: nama toko, kontak, nomor HP WhatsApp, dan tempo standar (misalnya 14 hari).
  4. Setiap ada penjualan tempo, catat di tab Piutang: pilih pelanggan, isi keterangan/faktur dan total — tanggal jatuh tempo dihitung otomatis dari tempo.
  5. Di tab Jatuh Tempo, lihat piutang yang sudah atau segera jatuh tempo. Kirim pengingat lewat tombol WhatsApp atau Salin Pengingat, lalu tekan Sudah Diingatkan.
  6. Saat pelanggan membayar, catat di tab Pembayaran: pilih piutang, isi jumlah dan metode (Tunai / Transfer / QRIS). Boleh dicicil — bila jumlah sama dengan sisa, piutang otomatis Lunas.
  7. Di tab Laporan, pilih bulan untuk melihat piutang baru, pembayaran diterima, dan umur piutang (berapa hari lewat jatuh tempo) per kelompok. Laporan bisa dicetak atau diunduh sebagai CSV. Di bawahnya ada Ringkasan per Cabang dan tombol Backup JSON / Pulihkan.
  8. Penghapusan piutang, pembayaran, dan pelanggan tidak langsung jalan — masuk ke tab Persetujuan dan menunggu disetujui Manager/Owner. Semua aksi tercatat di tab Audit Log.
  9. Semua data tersimpan otomatis di perangkat ini setiap kali ada perubahan (IndexedDB terenkripsi).

Masuk (Login), Peran & Pengguna

Saat aplikasi dibuka, layar masuk tampil lebih dulu. Ada 3 peran (hak akses ditegakkan di logika aplikasi, bukan hanya menyembunyikan tombol):

  • Owner — semua akses: piutang, pembayaran, pelanggan, persetujuan, audit, kelola pengguna, ekspor/backup, dan reset data.
  • Manager — piutang, pembayaran, pelanggan, persetujuan, audit, ekspor. Tidak bisa kelola pengguna. Tidak bisa memutuskan permintaan persetujuan yang diajukan sendiri.
  • Staf — catat piutang, pembayaran, dan pelanggan; lihat persetujuan. Tidak bisa menghapus piutang/pembayaran/pelanggan, tidak bisa kelola pengguna, dan tidak bisa melihat Audit Log.

Sesi masuk tersimpan selama tab peramban masih terbuka — memuat ulang halaman tidak meminta masuk lagi, tetapi menutup tab akan meminta masuk kembali. Klik Keluar di kanan atas untuk keluar. Owner bisa menambah pengguna, mengubah peran, dan menonaktifkan pengguna di kartu Kelola Pengguna di bawah.

Akun demo (untuk mencoba): Owner — owner / owner123; Manager — manager / manager123; Staf — staf / staf123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di kartu Kelola Pengguna. Kata sandi pengguna tersimpan terenkripsi di perangkat ini — jangan pakai kata sandi yang sama dengan akun penting lainnya.

Multi-cabang & Persetujuan

Aplikasi ini punya 3 cabang contoh: Cabang Pusat, Cabang Jakarta Timur, dan Cabang Bekasi. Pilih cabang aktif di tab Piutang — piutang, pembayaran, pelanggan, dan statistik mengikuti cabang itu; tabel "Ringkasan per Cabang" di tab Laporan menggabungkan ketiganya. Piutang, pembayaran, dan pelanggan baru selalu memakai cabang aktif. Tiga hal butuh persetujuan Manager/Owner dan tercatat di tab Persetujuan + Audit Log: hapus piutang (termasuk yang masih ada sisa), hapus pembayaran, dan hapus pelanggan.

Catatan penting (jujur)

Aplikasi ini berupa satu file HTML dan bekerja offline. Data pelanggan, piutang, dan pembayaran hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi), sekarang di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256) — kapasitas jauh lebih besar dari localStorage 5 MB dan data terenkripsi saat tersimpan. Jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Data tidak tersinkron ke perangkat lain dan tidak ada backup cloud otomatis — pakai tombol Backup JSON di tab Laporan secara berkala. Aplikasi ini BUKAN .exe native — dibuka lewat browser di laptop atau HP. Aplikasi ini tidak memproses pembayaran online sungguhan — pembayaran dicatat manual setelah uang diterima (tunai/transfer/QRIS di luar aplikasi). Untuk pemakaian bersama oleh banyak staf di perangkat berbeda (multi-user lintas perangkat) atau penyimpanan permanen di server dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
