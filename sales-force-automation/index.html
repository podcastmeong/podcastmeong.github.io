Panduan Penggunaan

Cara memakai Sales Force Automation (SFA), harga, dan garansi.

Cara memakai

  1. Di tab Kunjungan, tambahkan salesman di kartu Tim Salesman bila tim bertambah.
  2. Buat Rencana Kunjungan untuk setiap salesman: tanggal, jam, toko/pelanggan, alamat, dan prioritas.
  3. Setelah kunjungan dilaksanakan, isi Catat Hasil Kunjungan: pilih rencananya, pilih hasil (Order / Follow-up / Kunjungan Rutin / Tidak Bertemu), jam selesai, dan catatan.
  4. Bila pelanggan memesan, input di tab Pesanan: produk, jumlah, dan harga satuan — total dihitung otomatis. Ubah status menjadi Selesai setelah barang terkirim dan dibayar.
  5. Di tab Target, tetapkan target omzet dan target kunjungan bulanan tiap salesman, lalu pantau pencapaiannya lewat bilah progres.
  6. Di tab Monitoring, perbarui status lapangan tiap salesman (Berangkat / Tiba di Lokasi / Selesai / Istirahat) dan lihat linimasa aktivitas hari ini.
  7. Di tab Laporan, pilih bulan untuk melihat rekap kinerja tiap salesman — bisa dicetak atau disimpan sebagai PDF.
  8. Semua data tersimpan otomatis di perangkat ini setiap kali ada perubahan.
