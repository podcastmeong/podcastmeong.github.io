Panduan

Cara memakai Aplikasi Rental Kendaraan, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Kasir untuk membuat sewa, mengubah status, memproses pengembalian, mengelola kendaraan, dan membuka laporan; atau sebagai Mekanik untuk melihat kendaraan dan jadwal saja.
  2. Di tab Kendaraan, lihat semua unit beserta tarif harian dan statusnya. Kendaraan berstatus Perawatan tidak bisa disewakan sampai diubah kembali ke Tersedia.
  3. Di tab Sewa, buat sewa baru: pilih kendaraan yang tersedia, pelanggan, tanggal ambil dan kembali, lalu isi deposit. Total dihitung otomatis (tarif harian × jumlah hari) dan terlihat sebelum disimpan. Simpan sebagai Dipesan bila ambil masih nanti, atau Simpan & Mulai Sewa bila kendaraan langsung diambil.
  4. Klik Salin Teks WA pada sewa untuk menyalin rincian sewa ke pelanggan (lengkap dengan total dan deposit), lalu tempel di WhatsApp. Aplikasi ini hanya menyiapkan teks — pengiriman dilakukan manual lewat WhatsApp Anda.
  5. Saat kendaraan kembali, klik Pengembalian: isi tanggal kembali sebenarnya dan kondisi kendaraan. Bila terlambat, denda dihitung otomatis (denda per hari × hari terlambat). Bila ada kerusakan, catat di kondisi kembali — deposit bisa dipotong sesuai catatan.
  6. Di tab Jadwal, pantau sewa yang terlambat dikembalikan, ambil / kembali hari ini, dan agenda 7 hari ke depan. Di tab Laporan, lihat pendapatan rental per periode, lalu gunakan Ekspor CSV dan Backup JSON.
  7. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Kasir — kasir / kasir123; Mekanik — mekanik / mekanik123 (hanya melihat kendaraan dan jadwal). Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Rental Oyen (12 kendaraan — 6 mobil dan 6 motor, 8 pelanggan, 10 sewa: 2 aktif, 2 dipesan, 5 selesai, 1 batal). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Tarif dan denda pada aplikasi ini contoh — sesuaikan dengan tarif rental Anda. Deposit adalah jaminan, bukan pembayaran sewa: deposit dikembalikan saat kendaraan kembali dalam kondisi baik. Aplikasi ini bukan sistem akuntansi dan bukan payment gateway (pembayaran dicatat manual). Teks WhatsApp yang disalin dari aplikasi hanya teks — aplikasi tidak mengirim WhatsApp sendiri, kirim manual lewat WhatsApp Anda. Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh kasir dan mekanik di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
