Panduan

Cara memakai Aplikasi Property Management, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Agen untuk mengelola properti, penyewa, pembeli, dan jadwal showing; atau sebagai Pemilik untuk melihat properti milik Anda beserta penyewa, pembeli, dan jadwal showing-nya.
  2. Di tab Properti, tambah properti baru (rumah, apartemen, atau ruko) beserta harga jual, harga sewa, status, pemilik, dan agen. Status properti bisa diubah: Dijual menjadi Terjual, Disewakan menjadi Tersewa — dan sebaliknya bila transaksi batal.
  3. Di tab Penyewa, catat penyewa beserta masa sewa dan sewa bulanannya. Penyewa yang menunggak ditandai "Menunggak" supaya mudah ditagih.
  4. Di tab Pembeli, catat calon pembeli beserta harga tawarannya. Bila pembeli mencapai Deal, status propertinya otomatis berubah menjadi Terjual.
  5. Di tab Jadwal, buat jadwal showing: pilih properti, calon, tanggal, jam, dan agen pendamping. Klik Detail & Catatan untuk mengubah status dan menambahkan catatan kunjungan.
  6. Di tab Laporan, pilih periode dan properti lalu gunakan Ekspor CSV dan Backup JSON untuk arsip. Data contoh bisa dikembalikan dari kartu Data contoh di bawah.
  7. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Hartono + laporan). Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh PM Oyen (8 properti, 5 penyewa, 5 pembeli, 10 jadwal showing, 3 catatan: 3 properti Dijual, 1 Disewakan, 1 Terjual, 3 Tersewa; 2 penyewa Aktif, 1 Menunggak, 2 Selesai). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Status "Deal" pada pembeli mengubah status properti menjadi Terjual secara otomatis — pastikan harga tawaran sudah disepakati sebelum menandai Deal. Aplikasi ini bukan sistem akuntansi dan bukan payment gateway (pembayaran dicatat manual). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh tim di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
