Kelola Pengguna

Hanya admin yang melihat bagian ini. Admin bisa menambah pengguna, mengubah peran, menonaktifkan pengguna, dan mengganti kata sandi pengguna. Pengguna yang dinonaktifkan tidak bisa masuk. Kasir adalah operator bengkel: bisa melihat mekanik, work order, komisi, dan laporan — tapi tidak bisa mengelola pengguna, mekanik, dan aturan komisi. Mekanik hanya melihat work order dan komisinya sendiri.

Aturan Komisi Khusus

Aturan khusus untuk satu mekanik dan satu layanan — mengalahkan komisi standar mekanik itu. Tipe Persen dihitung dari harga jasa; tipe Nominal dibayar tetap per pekerjaan, berapapun harga jasanya. Hanya admin yang bisa mengubah aturan.

Panduan

Cara memakai Aplikasi Mekanik & Komisi, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna, mekanik, dan aturan komisi; sebagai Kasir untuk melihat mekanik, mencatat work order, menandai komisi dibayar, dan membuka laporan; atau sebagai Mekanik untuk melihat work order dan komisinya sendiri.
  2. Di tab Mekanik, kelola data mekanik (nama, spesialisasi, komisi standar) dan aturan komisi khusus per layanan. Aturan khusus mengalahkan komisi standar: tipe Persen dihitung dari harga jasa, tipe Nominal dibayar tetap per pekerjaan.
  3. Di tab Work Order, catat pekerjaan yang dikerjakan: kendaraan, tanggal, mekanik, jasa, dan spare part. Total biaya dan komisi mekanik dihitung otomatis dan terlihat sebelum disimpan. Komisi hanya dihitung untuk work order berstatus Selesai.
  4. Di tab Komisi, lihat rekap komisi tiap mekanik per periode. Klik Tandai Dibayar pada work order setelah komisinya diserahkan ke mekanik, atau Bayar Semua untuk membayar semua komisi yang belum dibayar pada periode yang sedang dipilih.
  5. Di tab Laporan, lihat kinerja mekanik per periode. Gunakan Ekspor CSV untuk mengunduh laporan, dan Backup JSON untuk menyimpan seluruh data; Pulihkan Backup mengembalikan data dari file backup.
  6. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Kasir — kasir / kasir123; Mekanik — mekanik / mekanik123 (melihat data mekanik Agus). Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Bengkel Oyen (5 mekanik, 14 layanan, 12 spare part, 8 pelanggan, 12 kendaraan — 6 mobil dan 6 motor, 17 work order, dan 4 aturan komisi khusus). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini menghitung komisi mekanik dari harga jasa saja — spare part tidak menghasilkan komisi. Komisi hanya dihitung untuk work order berstatus Selesai. Aplikasi ini bukan sistem akuntansi dan bukan sistem penggajian resmi (tidak menghitung pajak, BPJS, atau potongan gaji), dan bukan payment gateway (pembayaran komisi dicatat manual setelah uang diserahkan). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh kasir dan mekanik di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
