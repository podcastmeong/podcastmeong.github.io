Panduan

Cara memakai aplikasi Restaurant POS, harga, dan garansi.

Cara memakai

  1. Masuk dengan akun Anda — Admin (semua akses), Manajer (tanpa kelola pengguna), atau Kasir (melayani pesanan, tanpa hapus data). Akun demo: admin / admin123, manajer / manajer123, kasir / kasir123.
  2. Di tab Menu, lengkapi kategori dan item beserta harganya. Item yang habis ditandai agar tidak bisa dipesan di Kasir.
  3. Di tab Kasir, pilih meja, ketuk menu untuk masuk keranjang, lalu pilih bayar Tunai (kembalian dihitung otomatis) atau QRIS. Pesanan bisa juga Simpan Pesanan dulu — meja jadi terisi dan bisa dibayar belakangan di tab Meja.
  4. Servis 5% dan pajak restoran (PB1) 10% dihitung otomatis dari subtotal setelah diskon dan tampil jelas di keranjang dan struk. Diskon di atas 20% subtotal atau di atas Rp100.000 tidak langsung jalan — diajukan ke tab Persetujuan dan baru berlaku bila disetujui Admin/Manajer.
  5. Di tab Meja, lihat 10 meja: yang terisi berarti ada pesanan belum dibayar. Klik untuk membayar atau membatalkan.
  6. Di tab Laporan, lihat penjualan hari ini, item terlaris, dan riwayat pesanan beserta struknya.
  7. Pilih Outlet aktif di tab Dasbor atau Kasir — menu, meja, transaksi, dan statistik mengikuti outlet itu; laporan menampilkan ringkasan semua outlet.
  8. Aksi sensitif (hapus item menu, hapus transaksi, void/batalkan pesanan, dan diskon besar) tidak langsung jalan — diajukan ke tab Persetujuan dan baru berlaku bila disetujui Admin/Manajer. Semua tercatat di tab Audit Log.
  9. Semua data tersimpan otomatis di perangkat ini (IndexedDB + enkripsi) setiap kali ada perubahan. Cadangkan berkala dengan tombol Backup JSON di tab Laporan. Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Manajer — manajer / manajer123; Kasir — kasir / kasir123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Warung Kopi Oyen (4 kategori, 12 item, 1 item habis) di Outlet Pusat, plus Outlet Jakarta Timur dan Outlet Bekasi yang masih kosong. Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini berupa satu file HTML dan bekerja offline. Data menu, meja, pesanan, dan laporan hanya tersimpan di perangkat ini — sekarang di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256). Jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Data tidak tersinkron ke perangkat lain dan tidak ada backup cloud otomatis — pakai tombol Backup JSON di tab Laporan secara berkala. Aplikasi ini BUKAN .exe native — dibuka lewat browser di laptop atau HP. Aplikasi ini punya tiga peran pengguna (Admin, Manajer, Kasir) di perangkat ini. Untuk pemakaian bersama oleh banyak staf di perangkat berbeda (multi-user lintas perangkat) dan penyimpanan permanen di server dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
