Panduan

Cara memakai Aplikasi Servis Kendaraan, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Kasir untuk booking, work order, kasir, dan laporan; atau sebagai Mekanik untuk kendaraan, booking, work order, dan spare part.
  2. Di tab Kendaraan, kelola pelanggan dan kendaraannya: plat nomor, merek, tahun, kilometer, dan jadwal servis berkala. Klik Riwayat untuk melihat semua servis yang pernah dilakukan pada kendaraan itu.
  3. Di tab Booking, buat janji servis: kendaraan, tanggal, jam, dan keluhan. Saat pelanggan datang, klik Buat Work Order — booking berubah menjadi Datang.
  4. Di tab Work Order, kelola perintah kerja: diagnosa, mekanik, jasa, dan spare part yang dipakai. Ubah status dengan tombol Lanjut Status: Antre → Dikerjakan → Selesai. Spare part yang ditambahkan langsung mengurangi stok (bila stok tidak cukup, penambahan ditolak). Estimasi biaya dihitung otomatis: jasa + spare part − diskon.
  5. Di tab Kasir, bayar work order yang sudah Selesai: pilih work order, pilih metode bayar (Tunai / QRIS / Transfer), isi uang dibayar untuk melihat kembalian, lalu simpan. Work order berubah menjadi Diambil dan masuk omzet.
  6. Di tab Laporan, lihat transaksi, omzet, dan laba per periode, serta jasa terlaris. Gunakan Ekspor CSV untuk mengunduh laporan, dan Backup JSON untuk menyimpan seluruh data; Pulihkan Backup mengembalikan data dari file backup.
  7. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Kasir — kasir / kasir123; Mekanik — mekanik / mekanik123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Bengkel Oyen (8 pelanggan, 12 kendaraan, 12 jasa, 14 spare part, 6 booking, 8 work order, dan 4 pembayaran dalam 8 hari terakhir). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini mencatat pelanggan, kendaraan, booking, work order, stok spare part, pembayaran, omzet, dan laba dari selisih harga jual dan harga beli spare part — bukan sistem akuntansi (tidak menghitung gaji mekanik, sewa bengkel, listrik, atau biaya lain selain harga beli spare part) dan bukan payment gateway (kasir mencatat pembayaran Tunai / QRIS / Transfer secara manual). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh kasir dan mekanik di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
