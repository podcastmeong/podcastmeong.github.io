Panduan

Cara memakai Crop Monitoring.

Cara Memakai

  1. Masuk dengan salah satu akun demo di bawah.
  2. Buka tab Lahan untuk melihat atau menambah lahan (jenis tanaman, luas, tanggal tanam, penanggung jawab, dan status).
  3. Buka tab Pertumbuhan untuk mencatat tinggi tanaman (cm) dan fase tumbuh berkala. Grafik menunjukkan tinggi terakhir tiap lahan.
  4. Buka tab Jadwal untuk menjadwalkan penyiraman dan pemupukan. Tandai Sudah Selesai setelah kegiatan dilakukan; jadwal yang lewat tanggal akan tampil sebagai peringatan.
  5. Buka tab Hama untuk mencatat hama dan penyakit beserta tingkat serangan dan tindakan. Tandai Tertangani bila sudah teratasi.
  6. Buka tab Foto untuk mengunggah foto perkembangan tanaman per lahan. Foto disimpan sebagai data URL di perangkat ini saja.
  7. Buka tab Laporan untuk rekap per lahan, per bulan, dan per tingkat hama, serta ekspor ke CSV.

Peran Pengguna

  • Admin — semua akses, termasuk kelola pengguna dan melihat semua catatan.
  • Manajer — mengelola lahan, pertumbuhan, jadwal, hama, foto, dan laporan. Tidak bisa kelola pengguna.
  • Petani — melihat jadwal dan lahan miliknya; mencatat pertumbuhan, jadwal, hama, dan foto untuk lahannya sendiri. Tidak bisa menambah lahan dan tidak bisa menghapus catatan orang lain.

Batasan yang Jujur

  • Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.
  • Aplikasi ini bukan sistem multi-perangkat dan bukan payment gateway. Tidak ada sinkronisasi antar-perangkat dan tidak ada pembayaran otomatis.
  • Foto disimpan sebagai data URL di perangkat ini — foto berukuran besar memakai ruang penyimpanan perangkat. Periksa kondisi tanaman secara langsung — aplikasi ini hanya alat pencatatan, bukan pengganti pengamatan lapangan atau penyuluh pertanian.
