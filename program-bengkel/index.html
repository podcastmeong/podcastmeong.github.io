Panduan Penggunaan

Buku panduan lengkap Program Bengkel, termasuk ketentuan garansi.

1. Memulai

Program Bengkel adalah aplikasi pencatatan untuk bengkel motor dan mobil skala kecil. Aplikasi dibuka langsung dari berkas HTML di peramban (browser) — di HP, tablet, atau komputer — tanpa perlu memasang program tambahan. Saat pertama dibuka, aplikasi berisi data contoh (8 work order, 8 pelanggan, 4 mekanik, dan 12 spare part) agar Anda bisa langsung mencoba semua fitur. Ganti data contoh dengan data bengkel Anda sendiri lewat tombol Tambah, Ubah, dan Hapus di setiap tab.

2. Tab Ringkasan

Tab Ringkasan menampilkan gambaran bengkel hari ini:

  • Pekerjaan hari ini — jumlah work order yang masuk pada tanggal hari ini.
  • Pemasukan hari ini — total estimasi biaya dari work order berstatus Selesai pada hari ini.
  • Work order aktif — jumlah work order berstatus Antrean dan Dikerjakan.
  • Stok spare part menipis — jumlah spare part yang stoknya sudah mencapai atau di bawah batas minimum.
  • Daftar Pekerjaan Hari Ini dan daftar Stok Menipis untuk tindak lanjut cepat.

3. Tab Work Order

Work order adalah catatan pekerjaan servis untuk satu kendaraan.

  • Mencari: ketik nama pelanggan, kendaraan, keluhan, atau layanan di kotak pencarian.
  • Memfilter: gunakan tombol Semua, Antrean, Dikerjakan, atau Selesai.
  • Menambah: klik Tambah Work Order, lalu isi pelanggan, kendaraan, keluhan, layanan yang dikerjakan, estimasi biaya, mekanik penanggung jawab, dan status awal.
  • Mengubah status: pilih status baru langsung dari daftar pilihan pada kartu work order (Antrean → Dikerjakan → Selesai).
  • Mengubah isi: klik ikon pensil untuk mengubah data work order.
  • Menghapus: klik ikon tempat sampah, lalu konfirmasi. Work order yang terhapus tidak bisa dikembalikan.

4. Tab Pelanggan & Kendaraan

  • Setiap pelanggan dicatat bersama satu kendaraannya: jenis (Motor atau Mobil), merek dan model, tahun, serta nomor polisi.
  • Gunakan pencarian untuk menemukan pelanggan dari nama, kendaraan, atau nomor polisi; gunakan filter Motor/Mobil untuk menyaring jenis kendaraan.
  • Klik Tambah Pelanggan untuk mencatat pelanggan baru, ikon pensil untuk mengubah, dan ikon tempat sampah untuk menghapus.
  • Pelanggan yang sudah tercatat otomatis muncul sebagai pilihan saat Anda membuat work order baru.

5. Tab Spare Part

  • Setiap spare part dicatat dengan kode, nama, kategori, stok saat ini, batas minimum stok, satuan, dan harga satuan.
  • Bila stok mencapai atau turun di bawah batas minimum, spare part ditandai Menipis; bila stok nol, ditandai Habis. Peringatan juga muncul di tab Ringkasan dan pada menu Spare Part.
  • Gunakan pencarian, filter kategori, dan filter status stok (Tersedia / Menipis / Habis) untuk menemukan barang dengan cepat.
  • Perbarui angka stok setiap kali ada barang masuk atau terpakai, agar peringatan stok selalu akurat.

6. Tab Mekanik

Tab Mekanik menampilkan setiap mekanik beserta spesialisasinya, jumlah pekerjaan yang sedang ditangani (Antrean dan Dikerjakan), jumlah pekerjaan selesai, dan daftar work order aktifnya. Daftar ini terisi otomatis dari data work order — bila Anda mengganti mekanik pada sebuah work order, tampilan di tab ini ikut berubah.

7. Garansi

Garansi perbaikan bug/error. Setiap pembelian Program Bengkel dilengkapi garansi perbaikan bug atau error pada fitur-fitur yang tercantum di buku panduan dan versi demo aplikasi ini. Perbaikan selama masa garansi gratis — Anda tidak dikenai biaya tambahan untuk perbaikan tersebut.

Masa garansi:

Cara BeliPaketMasa Garansi
Beli SekaliPemula30 hari
Beli SekaliProfesional60 hari
Beli SekaliBisnis90 hari
BerlanggananSemua paketSelama masa langganan aktif

Yang termasuk garansi:

  • Perbaikan bug/error pada fitur yang ada di buku panduan dan demo (misalnya tombol tidak berfungsi, hitungan ringkasan salah, atau tampilan rusak).

Yang tidak termasuk garansi:

  • Permintaan fitur baru di luar buku panduan dan demo.
  • Perubahan desain, tampilan, atau struktur data di luar versi yang diterima.
  • Kerusakan atau error yang timbul karena pembeli mengubah berkas aplikasi sendiri.
  • Gangguan yang berasal dari layanan pihak ketiga (misalnya peramban, perangkat, atau jaringan internet pembeli).

Cara klaim: hubungi penjual melalui WhatsApp dan sertakan video atau screenshot yang menunjukkan bug/error-nya, beserta penjelasan singkat langkah yang Anda lakukan sebelum error muncul. Bukti visual membantu perbaikan dilakukan lebih cepat dan tepat.

8. Batasan & Catatan Penting

  • Data pada versi ini hanya tersimpan selama aplikasi dibuka. Menutup atau memuat ulang halaman akan mengembalikan data ke data contoh awal. Simpan catatan penting Anda juga di tempat lain.
  • Program Bengkel adalah aplikasi pencatatan bengkel untuk membantu operasional harian — bukan sistem kasir pajak dan tidak menerbitkan dokumen perpajakan.
  • Angka "Pemasukan hari ini" adalah total estimasi biaya work order yang selesai hari ini, bukan laporan keuangan resmi.
