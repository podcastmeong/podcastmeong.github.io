Panduan

Cara memakai Aplikasi Pemesanan Makanan (Self-Order), harga, dan garansi.

Cara memakai — pelanggan

  1. Pelanggan membuka halaman ini (atau memindai kode QR di meja) — tanpa login.
  2. Pilih meja (atau Bungkus), lalu pilih menu dan tekan + Tambah untuk memasukkan ke keranjang.
  3. Di Keranjang, atur jumlah, tulis catatan untuk dapur bila ada, lalu klik Kirim Pesanan.
  4. Catat kode pesanan (contoh: APM-001). Lacak statusnya di kartu Lacak Pesanan: Baru → Diproses → Siap → Selesai.
  5. Bayar di kasir (tunai / QRIS) saat pesanan diserahkan. Aplikasi ini mencatat pesanan — pembayaran tetap di kasir.

Cara memakai — pengelola

  1. Masuk sebagai Admin (semua akses), Manajer (memproses pesanan dan kelola menu, tanpa kelola pengguna), atau Kasir (memproses pesanan, tanpa hapus data dan tanpa tab Persetujuan/Audit).
  2. Pilih Outlet aktif di tab Dasbor — menu, pesanan, dan statistik mengikuti outlet itu. Pelanggan juga memilih outlet di halaman pesan. Ringkasan semua outlet ada di tab Dasbor.
  3. Di tab Pesanan, pesanan baru masuk sebagai Baru. Klik Mulai Proses saat dapur mengerjakan, Tandai Siap saat selesai dimasak, lalu Selesai / Serahkan saat pesanan diserahkan dan dibayar. Membatalkan pesanan tidak langsung jalan — diajukan ke tab Persetujuan.
  4. Di tab Menu, tambah item baru atau tandai item habis — pelanggan langsung tidak bisa memesannya. Menghapus item menu diajukan ke tab Persetujuan dan baru berlaku bila disetujui Admin/Manajer.
  5. Di tab Rekomendasi, lihat menu terlaris yang otomatis ditandai di halaman pelanggan.
  6. Di tab Persetujuan, Admin/Manajer menyetujui atau menolak permintaan hapus menu, void/batalkan pesanan, dan hapus pesanan. Semua keputusan tercatat di tab Audit Log.
  7. Semua data tersimpan otomatis di perangkat ini (IndexedDB + enkripsi) setiap kali ada perubahan. Cadangkan berkala dengan tombol Backup JSON di tab Riwayat. Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Manajer — manajer / manajer123; Kasir — kasir / kasir123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Fitur Level 4

  1. Penyimpanan IndexedDB + enkripsi AES-GCM 256 (WebCrypto): seluruh data (menu, pesanan, pengguna, persetujuan, audit) tersimpan terenkripsi di perangkat ini. Data lama dari localStorage dimigrasikan otomatis saat pertama dibuka.
  2. Multi-outlet: 3 outlet — Pusat, Jakarta Timur, Bekasi. Menu dan pesanan mengikuti outlet aktif; Dasbor menampilkan ringkasan semua outlet.
  3. Tiga peran: Admin (semua akses), Manajer (proses pesanan + kelola menu, tanpa kelola pengguna), Kasir (proses pesanan saja; tidak melihat tab Persetujuan & Audit).
  4. Alur persetujuan: hapus item menu, void/batalkan pesanan, dan hapus pesanan harus disetujui Admin/Manajer di tab Persetujuan.
  5. Audit Log: login, logout, perubahan menu, perubahan status pesanan, keputusan persetujuan, backup/restore, dan ganti outlet tercatat dengan pengguna, waktu, dan outlet.
  6. Backup JSON: unduh seluruh data sebagai file JSON dan pulihkan dari file backup (pulihkan hanya Admin/Manajer).

Data contoh

Aplikasi ini memakai data contoh Warung Kopi Oyen (4 kategori, 12 item menu, 7 pesanan contoh) di Outlet Pusat; Outlet Jakarta Timur dan Outlet Bekasi masih kosong. Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini mencatat pesanan pelanggan dan statusnya — bukan sistem pembayaran. Pembayaran tetap di kasir (tunai/QRIS). Data menu dan pesanan hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Data kini tersimpan di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256) — jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Tidak ada backup cloud otomatis — pakai tombol Backup JSON di tab Riwayat secara berkala. Bila pelanggan pesan dari HP-nya sendiri, pengelola perlu membuka aplikasi yang sama di perangkat yang terhubung ke server — untuk dipakai bersama di perangkat berbeda (multi-perangkat), dibutuhkan versi server; silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut. Aplikasi ini cocok dipasangkan dengan Restaurant POS dan Kitchen Display System kami.
