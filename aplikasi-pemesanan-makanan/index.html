Panduan

Cara memakai Aplikasi Pemesanan Makanan (Self-Order), harga, dan garansi.

Cara memakai — pelanggan

  1. Pelanggan membuka halaman ini (atau memindai kode QR di meja) — tanpa login.
  2. Pilih meja (atau Bungkus), lalu pilih menu dan tekan + Tambah untuk memasukkan ke keranjang.
  3. Di Keranjang, atur jumlah, tulis catatan untuk dapur bila ada, lalu klik Kirim Pesanan.
  4. Catat kode pesanan (contoh: APM-001). Lacak statusnya di kartu Lacak Pesanan: Baru → Diproses → Siap → Selesai.
  5. Bayar di kasir (tunai / QRIS) saat pesanan diserahkan. Aplikasi ini mencatat pesanan — pembayaran tetap di kasir.

Cara memakai — pengelola

  1. Masuk sebagai Admin (mengatur pengguna dan menu) atau Kasir (memproses pesanan).
  2. Di tab Pesanan, pesanan baru masuk sebagai Baru. Klik Mulai Proses saat dapur mengerjakan, Tandai Siap saat selesai dimasak, lalu Selesai / Serahkan saat pesanan diserahkan dan dibayar.
  3. Di tab Menu, tambah item baru atau tandai item habis — pelanggan langsung tidak bisa memesannya.
  4. Di tab Rekomendasi, lihat menu terlaris yang otomatis ditandai di halaman pelanggan.
  5. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Kasir — kasir / kasir123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Catatan penting (jujur)

Aplikasi ini mencatat pesanan pelanggan dan statusnya — bukan sistem pembayaran. Pembayaran tetap di kasir (tunai/QRIS). Data menu dan pesanan hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Bila pelanggan pesan dari HP-nya sendiri, pengelola perlu membuka aplikasi yang sama di perangkat yang terhubung ke server — untuk dipakai bersama di perangkat berbeda (multi-perangkat), dibutuhkan versi server; silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut. Aplikasi ini cocok dipasangkan dengan Restaurant POS dan Kitchen Display System kami.
