Cara Penjualan Game

Lima jalur distribusi yang masuk akal untuk kami — dari toko sendiri sampai portal game web.

1. Toko sendiri — jalur utama

File HTML dijual lewat toko, demo gratis di web, bayar manual via WhatsApp. Margin penuh, tanpa potongan platform. Ini cara kami menjual game hari ini.

2. itch.io — jalur kedua

Upload file HTML, main di browser, harga minimum + pay-what-you-want. Potongan default 10% + biaya prosesor US$0,30 + 2,9%. Audiens indie global, tanpa biaya publish.

3. Poki / CrazyGames — jalur trafik

Submit game; bila diterima, pendapatan dari iklan bagi hasil — CrazyGames 60% (iklan) / 70% (IAP) untuk developer, Playgama ~80%. Butuh kualitas portal & SDK; penghasilan tidak langsung dari penjualan file.

4. Google Play (APK) — jalur ketiga

Bungkus HTML jadi APK lewat Capacitor (sudah dilakukan untuk Kasir Toko). Butuh akun developer US$25 sekali bayar.

5. Galaxy Store

Akun seller gratis sudah ada (nama “masduki Kiki”). Distribusi untuk pengguna HP Samsung.

Bonus: uang dari iklan

Bila game dipasang di portal, uang datang dari iklan video berhadiah — eCPM 2026 sekitar US$15–28 di AS, US$8–15 di Eropa, US$1–3 di pasar tier-3. Kisaran jujur satu game kasual HTML5 yang lumayan: ~US$50–1.500/bulan, kebanyakan di ujung bawah.
