Panduan

Cara memakai Manajemen Bakery, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Kasir untuk pesanan, penjualan, dan laporan; atau sebagai Produksi untuk produk, bahan baku, dan produksi.
  2. Di tab Produk, kelola roti dan kue: harga jual, resep bahan, dan stok. Biaya bahan dan margin dihitung otomatis dari resep. Produk yang masih dipakai pesanan, penjualan, atau produksi tidak bisa dihapus.
  3. Di tab Bahan Baku, kelola stok bahan: stok, batas minimum, dan tanggal kadaluarsa. Bahan yang menipis atau mendekati kadaluarsa muncul sebagai peringatan di Dasbor.
  4. Di tab Produksi, buat batch produksi harian. Ubah status dengan tombol Lanjut Status: Direncanakan → Diproduksi → Selesai. Saat batch Selesai, bahan baku otomatis berkurang sesuai resep dan stok produk bertambah. Bila bahan tidak cukup, batch tidak bisa diselesaikan.
  5. Di tab Pesanan, buat pesanan pelanggan (pre-order): pelanggan, produk, jumlah, tanggal, dan cara terima. Ubah status dengan tombol Lanjut Status: Baru → Disiapkan → Selesai. Pesanan Selesai mengurangi stok produk dan masuk omzet.
  6. Di tab Kasir, catat penjualan langsung: tambah produk ke keranjang, pilih metode bayar (Tunai / QRIS / Transfer), isi uang dibayar untuk melihat kembalian, lalu simpan. Stok produk berkurang otomatis.
  7. Di tab Laporan, lihat transaksi, unit terjual, omzet, dan laba per periode, serta produk terlaris. Gunakan Ekspor CSV untuk mengunduh laporan, dan Backup JSON untuk menyimpan seluruh data; Pulihkan Backup mengembalikan data dari file backup.
  8. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Catatan penting (jujur)

Aplikasi ini mencatat produk, resep, stok bahan, produksi, pesanan, penjualan, dan laba dari biaya bahan — bukan sistem akuntansi (tidak menghitung gaji, sewa, listrik, gas, atau biaya lain selain biaya bahan) dan bukan payment gateway (kasir mencatat pembayaran Tunai / QRIS / Transfer secara manual). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh dapur dan kasir di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
