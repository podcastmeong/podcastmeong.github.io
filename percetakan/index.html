Panduan

Cara memakai Percetakan — Manajemen Order Cetak.

Cara Memakai

  1. Masuk dengan salah satu akun demo di bawah.
  2. Buka tab Harga untuk melihat tarif per bahan dan ukuran. Tarif hanya bisa diubah Admin dan Manajer.
  3. Buka tab Pelanggan untuk mencatat pelanggan baru, lalu tab Order untuk menerima order. Harga dihitung otomatis (tarif × ukuran × jumlah) dan ditampilkan sebelum disimpan.
  4. Buka tab Status untuk memajukan pengerjaan: Diterima → Dicetak → Selesai → Diambil. Order hanya bisa dibatalkan selama masih Diterima atau Dicetak.
  5. Buka tab Kasir untuk mencatat pembayaran. Pembayaran pertama minimal 50% (DP); pembayaran tidak boleh melebihi sisa tagihan; bila tunai, kembalian dihitung dari uang diterima.
  6. Buka tab Laporan untuk rekap order per jenis, per bahan, dan per bulan, serta ekspor order ke CSV.

Peran Pengguna

  • Admin — semua akses, termasuk kelola pengguna dan melihat semua data.
  • Manajer — mengelola order, harga, status, pelanggan, kasir, dan laporan. Tidak bisa kelola pengguna.
  • Kasir — melihat order, mencatat pembayaran, dan melihat laporan. Tidak bisa menambah order, mengubah tarif, atau kelola pengguna.

Batasan yang Jujur

  • Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.
  • Aplikasi ini bukan sistem multi-perangkat dan bukan payment gateway. Tidak ada sinkronisasi antar-perangkat dan tidak ada pembayaran otomatis — pembayaran hanya dicatat, uangnya tetap diterima di luar aplikasi.
  • Harga order memakai tarif saat order dibuat (snapshot). Bila tarif diubah setelahnya, total order lama tidak berubah.
  • Ukuran cetak memakai meter untuk Banner/Spanduk (lebar × tinggi) dan jumlah lembar/pcs untuk Brosur, Kartu Nama, dan Stiker. Ukuran khusus di luar daftar ditangani lewat keterangan order dan tarif yang disesuaikan manual oleh Manajer.
