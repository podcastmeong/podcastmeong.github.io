Panduan

Cara memakai Aplikasi Booking Servis, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Kasir untuk booking, antrean, work order, pengingat, dan laporan; atau sebagai Mekanik untuk kendaraan, booking, antrean, dan work order.
  2. Di tab Kendaraan, kelola pelanggan dan kendaraan mobil maupun motornya: plat nomor, merek, tahun, kilometer, dan jadwal servis berkala (mobil setiap 180 hari / 10.000 km, motor setiap 90 hari / 2.000 km). Klik Riwayat untuk melihat semua booking dan work order kendaraan itu.
  3. Di tab Booking, buat janji servis: kendaraan, tanggal, jam, layanan, mekanik, dan keluhan. Saat pelanggan datang, klik Tandai Datang, lalu klik Buat Work Order — booking berubah menjadi Datang dan work order dibuat dengan diagnosa yang sama.
  4. Di tab Antrean, lihat urutan kerja hari ini dan slot jadwal 08:00–17:00: slot yang sudah terisi menampilkan booking atau work order pada jam itu.
  5. Di tab Work Order, kelola perintah kerja: diagnosa, mekanik, dan jasa yang dikerjakan. Ubah status dengan tombol Lanjut Status: Antre → Dikerjakan → Selesai → Diambil. Saat menjadi Diambil, booking asalnya otomatis menjadi Selesai dan jadwal servis berkala kendaraan diperbarui. Estimasi biaya dihitung otomatis: jasa − diskon.
  6. Di tab Pengingat, salin teks pengingat booking besok (H-1) dan pengingat servis berkala, lalu kirim manual lewat WhatsApp atau SMS — aplikasi tidak mengirim pesan sendiri. Setelah dikirim, klik Sudah Diingatkan.
  7. Di tab Laporan, lihat jumlah booking per status dan layanan yang paling sering dipesan. Gunakan Ekspor CSV untuk mengunduh laporan, dan Backup JSON untuk menyimpan seluruh data; Pulihkan Backup mengembalikan data dari file backup.
  8. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Kasir — kasir / kasir123; Mekanik — mekanik / mekanik123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Bengkel Oyen (8 pelanggan, 12 kendaraan — 6 mobil dan 6 motor, 12 layanan, 12 booking, dan 4 work order). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini mencatat pelanggan, kendaraan, booking, antrean, work order, pengingat, dan laporan booking — bukan sistem akuntansi dan bukan payment gateway (tidak ada kasir dan pembayaran di aplikasi ini). Pengingat berupa teks saja — aplikasi tidak mengirim SMS atau WhatsApp sendiri; pesan harus disalin dan dikirim manual. Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh kasir dan mekanik di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
