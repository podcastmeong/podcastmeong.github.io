Ringkasan per Salesman —

Omzet dihitung dari pesanan berstatus Selesai. Komisi otomatis 5% dari omzet (dapat diubah di tab Komisi).

Tambah Salesman

Satu salesman: nama, wilayah penjualan, nomor HP, dan tanggal mulai bergabung.

Daftar Salesman

Ubah data atau ajukan penghapusan salesman yang sudah tidak bekerja — penghapusan butuh persetujuan Manager/Owner di tab Persetujuan. Menghapus salesman tidak menghapus riwayat kunjungan dan pesanannya.

Target & Pencapaian

Tetapkan target omzet dan target kunjungan bulanan per salesman, lalu pantau pencapaiannya.

Tambah Target Bulanan

Satu salesman hanya punya satu target per bulan — bila sudah ada, gunakan tombol Ubah pada daftar di bawah.

Pencapaian Target

Pencapaian omzet dihitung dari pesanan Selesai pada bulan target. Pencapaian kunjungan dihitung dari jumlah kunjungan tercatat.

Kunjungan Pelanggan

Catat setiap kunjungan salesman ke toko / pelanggan: hasil kunjungan dan tindak lanjutnya.

Tambah Kunjungan

Catat kunjungan segera setelah salesman pulang dari lapangan agar laporan akurat.

Riwayat Kunjungan

Kunjungan terbaru tampil paling atas.

Pesanan Lapangan

Pesanan yang diinput salesman langsung dari lapangan — total dihitung otomatis dari jumlah × harga satuan.

Tambah Pesanan

Pesanan berstatus Selesai masuk ke perhitungan omzet dan komisi. Pesanan Batal tidak dihitung.

Total pesanan: Rp0 (jumlah × harga satuan).

Daftar Pesanan

Pesanan terbaru tampil paling atas. Ubah status menjadi Selesai setelah barang terkirim dan dibayar. Penghapusan pesanan butuh persetujuan Manager/Owner.

Komisi Penjualan

Komisi dihitung otomatis dari omzet pesanan Selesai. Ubah persentasenya bila kebijakan perusahaan berubah.

Pengaturan Komisi

Perubahan tarif tidak langsung berlaku — diajukan dulu ke tab Persetujuan dan baru berlaku setelah disetujui Manager/Owner.

Contoh: omzet Rp10.000.000 dengan komisi 5% = Rp500.000.

Komisi per Salesman

Pilih bulan untuk melihat komisi bulan tersebut. Tandai Dibayar setelah komisi diserahkan ke salesman.

Rincian Pesanan Pembentuk Komisi

Hanya pesanan berstatus Selesai pada bulan yang dipilih yang membentuk komisi.

Panduan Penggunaan

Cara memakai Aplikasi Salesman, harga, dan garansi.

Masuk & peran

  • Owner — semua akses: data, persetujuan, audit, pengguna, ekspor/backup, dan reset data.
  • Manager — semua kecuali kelola pengguna; bisa menyetujui/menolak pengajuan.
  • Staf — input harian (salesman, target, kunjungan, pesanan). Tidak bisa menghapus salesman, mengubah tarif komisi, mengelola pengguna, atau melihat Audit Log — penghapusan dan perubahan tarif diajukan dulu ke Persetujuan.

Sesi masuk tersimpan selama tab peramban masih terbuka — memuat ulang halaman tidak meminta masuk lagi, tetapi menutup tab akan meminta masuk kembali. Owner bisa menambah pengguna, mengubah peran, dan menonaktifkan pengguna di tab Pengguna.

Cara memakai

  1. Tambahkan Salesman di tab Salesman: nama, wilayah, nomor HP, dan tanggal bergabung.
  2. Di tab Target, tetapkan target omzet dan target kunjungan bulanan untuk setiap salesman.
  3. Setiap selesai kunjungan, catat di tab Kunjungan: pelanggan, hasil kunjungan, dan catatan tindak lanjut.
  4. Bila pelanggan memesan, input di tab Pesanan Lapangan: produk, jumlah, dan harga satuan — total dihitung otomatis.
  5. Ubah status pesanan menjadi Selesai setelah barang terkirim. Pesanan Selesai masuk ke omzet dan komisi.
  6. Di tab Komisi, lihat komisi otomatis tiap salesman (standar 5% dari omzet) dan tandai Dibayar setelah diserahkan.
  7. Di tab Laporan, pilih bulan dan lihat rekap kinerja tiap salesman — bisa dicetak atau disimpan sebagai PDF.
  8. Masuk dulu dengan akun Anda (Owner / Manager / Staf) — akun demo tertera di layar masuk. Staf hanya bisa input harian; penghapusan dan perubahan tarif komisi harus disetujui Manager/Owner.
  9. Pilih Cabang Aktif di tab Salesman sebelum menginput — data baru masuk ke cabang itu, dan statistik mengikuti cabang aktif. Laporan menampilkan ringkasan semua cabang.
  10. Pengajuan yang menunggu persetujuan ada di tab Persetujuan; riwayat semua aksi ada di tab Audit Log (hanya Owner/Manager).
  11. Cadangkan data berkala lewat Backup JSON di tab Laporan — file backup bisa dipulihkan lewat tombol Pulihkan dari File JSON.
  12. Semua data tersimpan otomatis di perangkat ini setiap kali ada perubahan (IndexedDB terenkripsi).

Catatan penting (jujur)

Aplikasi ini berupa satu file HTML dan bekerja offline. Data salesman, target, kunjungan, pesanan, dan komisi hanya tersimpan di perangkat ini — sekarang di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256), kapasitas jauh lebih besar dari localStorage. Jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Data tersimpan PER PERANGKAT dan tidak tersinkron ke perangkat lain — pakai tombol Backup JSON di tab Laporan secara berkala. Data pengguna aplikasi (nama, peran, kata sandi) juga hanya tersimpan di perangkat ini. Aplikasi ini BUKAN .exe native — dibuka lewat browser di laptop atau HP. Untuk pemakaian bersama oleh banyak staf di perangkat berbeda (multi-user lintas perangkat) dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
