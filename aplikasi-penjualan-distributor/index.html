Persetujuan

Permintaan yang butuh persetujuan Manager/Owner: hapus pesanan, hapus faktur, perubahan harga produk di atas 25%, dan diskon pesanan di atas 20%. Keputusan tercatat di Audit Log.

Panduan Penggunaan

Cara memakai Aplikasi Penjualan Distributor, harga, dan garansi.

Cara memakai

  1. Di tab Harga & Diskon, isi dulu Produk beserta tiga tingkat harganya (Ecer, Grosir, Distributor) dan Pelanggan beserta tingkat harga bawaannya. Atur Aturan Diskon bila ada diskon jumlah pembelian.
  2. Di tab Pesanan, pilih pelanggan, tambahkan produk satu per satu (harga satuan terisi otomatis sesuai tingkat pelanggan; ubah bila perlu), atur diskon pesanan, lalu Simpan Pesanan.
  3. Di tab Faktur, pilih pesanan yang sudah dibuat, isi jatuh tempo, lalu Buat Faktur. Klik Lihat Nota untuk melihat nota penjualan yang siap dicetak.
  4. Di tab Target, isi target omzet dan jumlah pesanan per bulan — pencapaiannya terhitung otomatis dari pesanan.
  5. Di tab Riwayat, cari dan saring semua transaksi berdasarkan bulan, status, atau nama pelanggan.
  6. Di tab Laporan, lihat omzet per bulan, pelanggan terbaik, dan produk terlaris, atau unduh laporan sebagai CSV.
  7. Masuk dengan akun Anda (Owner / Manager / Staf) — akun demo: owner / owner123, manager / manager123, staf / staf123. Sesi berlaku selama tab masih terbuka.
  8. Pilih Cabang aktif di tab Pesanan — pesanan, faktur, target, dan statistik mengikuti cabang itu; laporan menampilkan ringkasan semua cabang.
  9. Aksi sensitif (hapus pesanan/faktur, ubah harga >25%, diskon pesanan >20%) tidak langsung jalan — diajukan ke tab Persetujuan dan baru berlaku bila disetujui Manager/Owner. Semua tercatat di tab Audit Log.
  10. Semua data tersimpan otomatis di perangkat ini (IndexedDB + enkripsi) setiap kali ada perubahan. Cadangkan berkala dengan tombol Backup JSON di tab Laporan.

Catatan penting (jujur)

Aplikasi ini berupa satu file HTML yang berjalan di browser. Data pesanan, faktur, produk, pelanggan, dan target hanya tersimpan di perangkat ini — sekarang di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256). Jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Data tidak tersinkron ke perangkat lain dan tidak ada backup cloud otomatis — pakai tombol Backup JSON di tab Laporan secara berkala. Aplikasi bisa dipakai offline. Aplikasi ini bukan program .exe native. Untuk pemakaian bersama oleh banyak pengguna di perangkat berbeda (multi-user lintas perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
