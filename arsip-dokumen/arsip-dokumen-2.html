1. Memulai

Arsip Dokumen membantu Anda menjawab tiga pertanyaan yang sering bikin pusing di usaha kecil: dokumen itu ada atau tidak, nomornya berapa, dan disimpan di mana? Aplikasi dibuka langsung di browser — tidak perlu instal dan tidak perlu akun.

  1. Buka aplikasi, lihat tab Ringkasan untuk gambaran isi arsip Anda.
  2. Periksa tab Kategori — sesuaikan kelompok dokumen dengan usaha Anda.
  3. Catat dokumen pertama Anda lewat tab Tambah Dokumen.
  4. Gunakan tab Daftar Dokumen setiap kali mencari dokumen.

Aplikasi ini datang dengan 12 dokumen contoh dalam 5 kategori (Keuangan, SDM, Legal, Operasional, Proyek) agar Anda bisa langsung mencoba semua fitur. Dokumen contoh boleh diubah dan dihapus — anggap saja sebagai bahan latihan.

2. Tab Ringkasan

  • Total Dokumen — jumlah seluruh metadata dokumen yang tercatat.
  • Jumlah per Kategori — sebaran dokumen per kategori, lengkap dengan grafik batang sederhana.
  • Jumlah per Jenis File — sebaran menurut format: PDF, Word, Excel, dan Gambar.
  • Dokumen Terbaru — lima dokumen dengan tanggal paling baru, agar dokumen yang baru dicatat mudah dicek kembali.

3. Tab Daftar Dokumen

Mencari dan menyaring

  • Pencarian — ketik sebagian nama dokumen, nomor dokumen, atau kata di keterangan.
  • Filter Kategori & Jenis File — tampilkan hanya kelompok tertentu.
  • Filter Tanggal — batasi dengan tanggal dari–sampai.
  • Urutkan — menurut tanggal (terbaru/terlama), nama (A–Z / Z–A), atau kategori.
  • Atur Ulang Filter — mengembalikan semua saringan ke keadaan awal.

Mengelola dokumen

  • Detail — melihat seluruh metadata satu dokumen dalam satu tampilan.
  • Ubah — memperbaiki nama, kategori, jenis, tanggal, nomor, atau keterangan. Perubahan tersimpan begitu Anda menekan Simpan.
  • Hapus — menghapus metadata dokumen dari daftar. Anda akan diminta memastikan dulu. Menghapus di sini tidak menghapus file asli Anda — file asli memang tidak pernah disimpan di aplikasi ini.

4. Tab Tambah Dokumen

  • Nama Dokumen * — tulis nama yang akan Anda cari nanti, misalnya “Laporan Keuangan Oktober 2026”, bukan sekadar “Laporan”.
  • Kategori * — pilih dari daftar kategori. Belum ada kategori yang cocok? Buat dulu di tab Kategori.
  • Jenis File * — PDF, Word, Excel, atau Gambar, mengikuti format file aslinya.
  • Tanggal Dokumen * — tanggal yang tertera pada dokumen, bukan tanggal Anda mencatatnya.
  • Nomor Dokumen — nomor surat / nomor arsip bila ada. Boleh dikosongkan.
  • Keterangan — catatan bebas. Sangat disarankan menulis lokasi penyimpanan file asli di sini, contoh: “Drive > Legal > Kontrak” atau “Map merah, lemari arsip ruang belakang”.

Kolom bertanda * wajib diisi. Setelah disimpan, dokumen langsung muncul di Daftar Dokumen dan Ringkasan.

5. Tab Kategori

  • Tambah — buat kategori baru dengan nama dan keterangan.
  • Ubah — mengganti nama kategori akan otomatis mengganti label pada semua dokumen di dalamnya.
  • Hapus — hanya bisa untuk kategori yang sudah kosong. Ini disengaja, agar tidak ada dokumen yang kehilangan kelompoknya tanpa sengaja.

6. Mengunduh Daftar sebagai CSV

Tombol Unduh CSV di tab Daftar Dokumen mengunduh daftar dokumen yang sedang tampil (sesudah pencarian dan filter) sebagai berkas arsip-dokumen.csv. Berkas CSV bisa dibuka di Microsoft Excel, Google Sheets, atau LibreOffice — berguna untuk laporan, cadangan daftar arsip, atau dibagikan ke rekan kerja. Isinya: nama, kategori, jenis file, tanggal, nomor dokumen, dan keterangan.

7. Batasan Versi Ini — Wajib Dibaca

Aplikasi ini adalah pencatat arsip, bukan tempat penyimpanan file.

  • Versi 1 mencatat metadata dokumen saja (nama, kategori, jenis, tanggal, nomor, keterangan). File aslinya tidak diunggah dan tidak disimpan di dalam aplikasi.
  • Data yang Anda ketik — termasuk 12 dokumen contoh — hanya tersimpan selama aplikasi dibuka di tab browser ini. Menutup atau memuat ulang halaman akan mengembalikan aplikasi ke data contoh awal. Untuk menyimpan daftar secara permanen, unduh sebagai CSV.
  • Tidak ada akun, tidak ada sinkronisasi antarperangkat, dan tidak ada pencarian isi di dalam file.
  • Simpan file asli Anda di tempat yang aman dan punya cadangan, misalnya folder komputer plus Google Drive / hard disk eksternal — lalu catat lokasinya di kolom Keterangan.

8. Tips Pengarsipan yang Rapi

  • Satu pola nama untuk semua dokumen, misalnya “Jenis – Bulan Tahun”, agar pencarian konsisten.
  • Selalu isi nomor dokumen bila dokumennya bernomor — nomor adalah cara tercepat memastikan dokumen yang benar.
  • Selalu tulis lokasi file asli di Keterangan. Arsip yang tidak bisa ditemukan sama saja dengan arsip yang hilang.
  • Unduh CSV secara berkala (misalnya tiap akhir bulan) sebagai cadangan daftar arsip Anda.
  • Jangan membuat kategori terlalu banyak — 5–8 kategori yang jelas lebih mudah dirawat daripada 20 kategori yang tumpang tindih.

Yang ditanggung garansi

  • Perbaikan bug / error pada fitur yang ada di buku panduan ini dan di demo — misalnya tombol tidak berfungsi, perhitungan atau tampilan daftar salah, filter tidak bekerja, atau unduhan CSV gagal dibuat.
  • Perbaikan diberikan gratis selama masa garansi masih berlaku.

Yang tidak ditanggung garansi

  • Permintaan fitur baru di luar buku panduan dan demo.
  • Perubahan desain (warna, tata letak, tampilan) dan perubahan data / isi di luar perbaikan bug.
  • Kerusakan atau error yang timbul karena pembeli mengubah file aplikasi sendiri.
  • Gangguan yang berasal dari layanan pihak ketiga (misalnya browser, perangkat, atau layanan internet pembeli).
  • Kehilangan file dokumen asli milik pembeli — aplikasi ini tidak menyimpan file asli, sebagaimana dijelaskan di bagian Batasan.

Cara klaim garansi

  1. Hubungi penjual melalui WhatsApp.
  2. Kirimkan video atau screenshot yang memperlihatkan bug / error-nya, beserta keterangan singkat: fitur apa yang dipakai dan langkah apa yang dilakukan sebelum error muncul.
  3. Penjual akan memeriksa dan memperbaiki bug yang termasuk cakupan garansi, lalu mengirimkan file aplikasi yang sudah diperbaiki.

10. Pertanyaan yang Sering Muncul

Apakah file dokumen saya tersimpan di aplikasi ini?

Tidak. Yang tersimpan hanya catatannya (metadata). File asli tetap di tempat Anda menyimpannya — tulis lokasinya di kolom Keterangan.

Kenapa data saya hilang setelah halaman ditutup?

Karena versi demo / versi 1 ini menyimpan data hanya selama aplikasi dibuka. Unduh daftar sebagai CSV bila ingin menyimpan daftar arsip secara permanen.

Bisakah saya menambah jenis file selain PDF, Word, Excel, Gambar?

Di versi ini jenis file dibatasi empat pilihan tersebut. Untuk format lain, pilih yang paling dekat dan jelaskan format aslinya di Keterangan.

Bisakah kategori diganti namanya?

Bisa, lewat tab Kategori → Ubah. Semua dokumen di dalamnya otomatis mengikuti nama baru.

Bagaimana cara memindahkan daftar arsip ke Excel?

Tekan Unduh CSV di tab Daftar Dokumen, lalu buka berkasnya di Excel, Google Sheets, atau LibreOffice.
