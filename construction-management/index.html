Panduan

Cara memakai Aplikasi Construction Management, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Manajer Proyek untuk mengelola proyek, jadwal, anggaran, pekerja, dan material; atau sebagai Mandor untuk melihat proyek dan pekerja yang ditugaskan ke Anda, mengisi progres pekerjaan, dan memberi catatan progres.
  2. Di tab Proyek, buat proyek baru dengan lokasi, klien, dan anggaran proyek. Progres proyek dihitung otomatis dari rata-rata progres pekerjaan di proyek itu.
  3. Di tab Jadwal, buat pekerjaan baru: pilih proyek, mandor penanggung jawab, tanggal mulai dan tenggat, lalu isi progres. Klik Detail & Catatan untuk mengubah status dan progres, serta menambahkan catatan progres harian.
  4. Di tab Anggaran, catat item biaya per kategori (Material, Upah Pekerja, Peralatan, Lainnya) beserta rencana dan realisasinya. Proyek yang realisasinya melebihi rencana ditandai "Melebihi anggaran".
  5. Di tab Pekerja, kelola data pekerja dan mandor beserta proyek dan upah hariannya. Di tab Material, pantau stok material — material yang stoknya di bawah minimum ditandai "Stok menipis".
  6. Di tab Laporan, pilih periode dan proyek lalu gunakan Ekspor CSV dan Backup JSON untuk arsip. Data contoh bisa dikembalikan dari kartu Data contoh di bawah.
  7. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123 (semua akses, termasuk kelola pengguna); Manajer Proyek — manajer / manajer123 (proyek, jadwal, anggaran, pekerja, material, laporan; tidak bisa kelola pengguna); Mandor — mandor / mandor123 (hanya proyek dan pekerja yang ditugaskan ke Budi Santoso + laporan progres). Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh CM Oyen (5 proyek, 14 pekerjaan, 12 item anggaran, 8 pekerja, 10 material, 4 catatan progres: 6 pekerjaan selesai, 5 berjalan, 3 belum dimulai). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Progres proyek dihitung dari rata-rata progres pekerjaan di proyek itu — bukan dari jam kerja atau pengukuran lapangan. Aplikasi ini bukan sistem akuntansi dan bukan payment gateway (pembayaran dicatat manual). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh tim di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
