Panduan

Cara memakai Manajemen Meja, harga, dan garansi.

Cara memakai

  1. Masuk dengan akun Anda — Admin (semua akses), Manajer (kelola denah dan pemesanan, tanpa kelola pengguna), atau Kasir (denah meja, pemesanan, riwayat, laporan). Akun demo: admin / admin123, manajer / manajer123, kasir / kasir123.
  2. Pilih Outlet aktif di tab Dasbor, Denah Meja, atau Pemesanan — denah meja, pemesanan, dan statistik mengikuti outlet itu; laporan menampilkan ringkasan semua outlet (Pusat, Jakarta Timur, Bekasi).
  3. Di tab Denah Meja, klik meja untuk melihat detailnya. Meja Kosong bisa diduduki (isi nama pelanggan dan jumlah orang, tambahkan pesanan dari menu bila ada); meja Terisi bisa diselesaikan (meja kembali kosong dan masuk riwayat) atau dipindahkan ke meja kosong lain; meja Dipesan menunggu pelanggan datang. Admin/Manajer bisa menambah meja baru di bawah denah; menghapus meja diajukan ke tab Persetujuan.
  4. Di tab Pemesanan, buat pemesanan meja (nama, jumlah orang, tanggal, waktu). Saat pelanggan datang, klik Check-in agar meja menjadi terisi. Membatalkan pemesanan tidak langsung jalan — diajukan ke tab Persetujuan dan baru berlaku bila disetujui Admin/Manajer.
  5. Timer di tiap meja menunjukkan lama meja diduduki. Meja yang terisi lebih dari 60 menit ditandai di Dashboard — segera tanyakan apakah pelanggan sudah selesai.
  6. Di tab Riwayat, lihat semua sesi meja yang selesai dan pemesanan yang sudah selesai atau dibatalkan. Menghapus entri riwayat diajukan ke tab Persetujuan. Di tab Laporan, lihat perputaran tiap meja, rata-rata durasi duduk, meja paling laris, dan ringkasan semua outlet.
  7. Aksi sensitif (hapus meja, batalkan/void pemesanan, hapus riwayat) tidak langsung jalan — diajukan ke tab Persetujuan dan baru berlaku bila disetujui Admin/Manajer. Semua tercatat di tab Audit Log (login, perubahan status meja/pemesanan, keputusan persetujuan, backup/restore, ganti outlet).
  8. Semua data tersimpan otomatis di perangkat ini (IndexedDB + enkripsi) setiap kali ada perubahan. Cadangkan berkala dengan tombol Backup JSON di tab Laporan. Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Manajer — manajer / manajer123; Kasir — kasir / kasir123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Warung Kopi Oyen (10 meja di 3 zona, 4 kategori, 12 item menu, 2 pemesanan contoh, 4 sesi selesai contoh) di Outlet Pusat, plus Outlet Jakarta Timur dan Outlet Bekasi yang denahnya masih kosong. Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini berupa satu file HTML dan bekerja offline. Data denah, meja, pemesanan, dan laporan hanya tersimpan di perangkat ini — sekarang di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256). Jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Data tidak tersinkron ke perangkat lain dan tidak ada backup cloud otomatis — pakai tombol Backup JSON di tab Laporan secara berkala. Aplikasi ini BUKAN .exe native — dibuka lewat browser di laptop atau HP. Aplikasi ini mengatur denah, status, pemesanan, dan perputaran meja — bukan sistem kasir dengan pembayaran dan bukan sistem reservasi online yang terhubung ke pelanggan. Aplikasi ini punya tiga peran pengguna (Admin, Manajer, Kasir) di perangkat ini. Untuk pemakaian bersama oleh banyak staf di perangkat berbeda (multi-user lintas perangkat) dan penyimpanan permanen di server dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut. Aplikasi ini cocok dipasangkan dengan Restaurant POS, Kitchen Display System, dan Aplikasi Pemesanan Makanan kami.
