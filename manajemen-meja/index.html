Panduan

Cara memakai Manajemen Meja, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur pengguna, atau sebagai Kasir untuk mengelola meja.
  2. Di tab Denah Meja, klik meja untuk melihat detailnya. Meja Kosong bisa diduduki (isi nama pelanggan dan jumlah orang, tambahkan pesanan dari menu bila ada); meja Terisi bisa diselesaikan (meja kembali kosong dan masuk riwayat) atau dipindahkan ke meja kosong lain; meja Dipesan menunggu pelanggan datang.
  3. Di tab Pemesanan, buat pemesanan meja (nama, jumlah orang, tanggal, waktu). Saat pelanggan datang, klik Check-in agar meja menjadi terisi.
  4. Timer di tiap meja menunjukkan lama meja diduduki. Meja yang terisi lebih dari 60 menit ditandai di Dashboard — segera tanyakan apakah pelanggan sudah selesai.
  5. Di tab Riwayat, lihat semua sesi meja yang selesai dan pemesanan yang sudah selesai atau dibatalkan. Di tab Laporan, lihat perputaran tiap meja, rata-rata durasi duduk, dan meja paling laris.
  6. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Kasir — kasir / kasir123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Warung Kopi Oyen (10 meja di 3 zona, 4 kategori, 12 item menu, 2 pemesanan contoh, 4 sesi selesai contoh). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini mengatur denah, status, pemesanan, dan perputaran meja — bukan sistem kasir dengan pembayaran dan bukan sistem reservasi online yang terhubung ke pelanggan. Data meja dan pemesanan hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh kasir dan pelayan di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut. Aplikasi ini cocok dipasangkan dengan Restaurant POS, Kitchen Display System, dan Aplikasi Pemesanan Makanan kami.
