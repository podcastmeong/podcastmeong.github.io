Panduan

Cara memakai Aplikasi Asset Management, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Manajer untuk mengelola aset, nilai, perawatan, riwayat, dan laporan; atau sebagai Teknisi untuk mengerjakan jadwal perawatan dan riwayat perbaikan yang ditugaskan kepada Anda.
  2. Di tab Aset, tambah aset baru (bangunan, peralatan, atau kendaraan) beserta nilai perolehan, nilai saat ini, dan kondisinya. Kondisi aset bisa diubah: Baik, Perlu Perawatan, atau Rusak.
  3. Di tab Nilai, lihat nilai perolehan, nilai saat ini, dan penyusutan per aset dan per kategori. Nilai saat ini bisa disesuaikan lewat tombol Sesuaikan Nilai (admin dan manajer).
  4. Di tab Perawatan, buat jadwal perawatan: pilih aset, jenis perawatan, tanggal rencana, dan teknisi. Tandai Mulai saat dikerjakan dan Selesaikan beserta biayanya saat selesai — riwayat perbaikan tercatat otomatis.
  5. Di tab Riwayat, lihat semua perbaikan yang sudah dilakukan beserta teknisi dan biayanya. Riwayat baru juga bisa dicatat manual.
  6. Di tab Laporan, pilih periode dan kategori lalu gunakan Ekspor CSV dan Backup JSON untuk arsip. Data contoh bisa dikembalikan dari kartu Data contoh di bawah.
  7. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123 (semua akses, termasuk kelola pengguna); Manajer — manajer / manajer123 (aset, nilai, perawatan, riwayat, laporan; tidak bisa kelola pengguna); Teknisi — teknisi / teknisi123 (hanya jadwal perawatan dan riwayat perbaikan milik Budi Santoso). Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh PM Oyen (12 aset, 10 jadwal perawatan, 8 riwayat perbaikan: 2 Bangunan, 7 Peralatan, 3 Kendaraan; 8 Baik, 3 Perlu Perawatan, 1 Rusak; total nilai aset Rp5.690.500.000). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Nilai saat ini adalah taksiran setelah penyusutan, bukan hasil penilaian resmi (appraisal). Aplikasi ini bukan sistem akuntansi dan bukan payment gateway (pembayaran dicatat manual). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh tim di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
