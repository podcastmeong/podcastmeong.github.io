Panduan

Cara memakai Aplikasi Riwayat Kendaraan, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Kasir untuk kendaraan, riwayat, pengingat, dan laporan; atau sebagai Mekanik untuk kendaraan dan riwayat.
  2. Di tab Kendaraan, kelola pelanggan dan kendaraan mobil maupun motornya: plat nomor, merek, tahun, kilometer, dan jadwal servis berkala (mobil setiap 180 hari / 10.000 km, motor setiap 90 hari / 2.000 km). Klik Riwayat untuk melihat semua booking dan servis kendaraan itu.
  3. Di tab Riwayat, pilih kendaraan untuk melihat seluruh riwayatnya — booking, servis, jasa, spare part, dan biaya — dari tanggal terbaru. Gunakan Catat Servis Baru untuk mencatat pekerjaan yang selesai: centang jasa dan spare part, isi diskon, lalu simpan. Bila dicentang "Ini servis berkala", jadwal servis berikutnya kendaraan itu diperbarui ke tanggal servis ini.
  4. Di tab Pengingat, salin teks pengingat booking besok (H-1) dan pengingat servis berkala, lalu kirim manual lewat WhatsApp atau SMS — aplikasi tidak mengirim pesan sendiri. Setelah dikirim, klik Sudah Diingatkan.
  5. Di tab Laporan, lihat jumlah servis dan total biaya per periode dan per kendaraan. Gunakan Ekspor CSV untuk mengunduh laporan, dan Backup JSON untuk menyimpan seluruh data; Pulihkan Backup mengembalikan data dari file backup.
  6. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Kasir — kasir / kasir123; Mekanik — mekanik / mekanik123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Bengkel Oyen (8 pelanggan, 12 kendaraan — 6 mobil dan 6 motor, 14 layanan, 12 spare part, 15 catatan servis, dan 6 booking). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Aplikasi ini mencatat pelanggan, kendaraan, riwayat servis, pengingat, dan laporan riwayat — bukan sistem akuntansi dan bukan payment gateway (tidak ada kasir dan pembayaran di aplikasi ini). Pengingat berupa teks saja — aplikasi tidak mengirim SMS atau WhatsApp sendiri; pesan harus disalin dan dikirim manual. Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh kasir dan mekanik di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
