Panduan

Cara memakai Kitchen Display System, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur pengguna, atau sebagai Kasir untuk mengelola pesanan di dapur.
  2. Di tab Pesanan Baru, pilih meja dan menu, tulis catatan dapur bila ada, lalu klik Kirim ke Dapur. Pesanan masuk sebagai status Baru.
  3. Di tab Layar Dapur, pesanan tampil dalam 3 kolom: Baru, Dimasak, dan Siap. Klik Mulai Masak saat dapur mulai mengerjakan, Tandai Siap saat selesai dimasak, lalu Selesai / Serahkan saat pesanan diserahkan ke pelanggan.
  4. Timer di tiap pesanan menunjukkan lama menunggu. Pesanan yang menunggu lebih dari 15 menit ditandai merah dengan label LAMA — segera dahulukan.
  5. Di tab Riwayat, lihat semua pesanan beserta statusnya. Di tab Laporan, lihat pesanan selesai hari ini, rata-rata waktu masak, dan item terlaris.
  6. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Kasir — kasir / kasir123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Catatan penting (jujur)

Aplikasi ini menampilkan pesanan di layar dapur dan mencatat statusnya — bukan sistem kasir dengan pembayaran dan bukan sistem produksi restoran sungguhan. Data menu dan pesanan hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh kasir dan dapur di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
