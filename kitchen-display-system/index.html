Cara memakai

  1. Pilih Outlet aktif di tab Dashboard — pesanan, menu, dan statistik mengikuti outlet itu; laporan menampilkan ringkasan semua outlet.
  2. Masuk sebagai Admin (semua akses, termasuk kelola pengguna, persetujuan, dan audit), Dapur (ubah status pesanan, tanpa hapus data), atau Kasir (buat pesanan baru dan lihat riwayat).
  3. Di tab Pesanan Baru, pilih meja dan menu, tulis catatan dapur bila ada, lalu klik Kirim ke Dapur. Pesanan masuk sebagai status Baru.
  4. Di tab Layar Dapur, pesanan tampil dalam 3 kolom: Baru, Dimasak, dan Siap. Klik Mulai Masak saat dapur mulai mengerjakan, Tandai Siap saat selesai dimasak, lalu Selesai / Serahkan saat pesanan diserahkan ke pelanggan.
  5. Timer di tiap pesanan menunjukkan lama menunggu. Pesanan yang menunggu lebih dari 15 menit ditandai merah dengan label LAMA — segera dahulukan.
  6. Hapus pesanan, batalkan pesanan yang sudah Dimasak, dan hapus item menu butuh persetujuan Admin — ajukan dari tombol Hapus / Batalkan, lalu Admin menyetujui atau menolak di tab Persetujuan. Pembatalan pesanan status Baru boleh langsung.
  7. Di tab Riwayat, lihat semua pesanan beserta statusnya. Di tab Laporan, lihat pesanan selesai hari ini, rata-rata waktu masak, item terlaris, dan ringkasan semua outlet. Tab Audit Log (hanya Admin) mencatat siapa melakukan apa dan kapan.
  8. Semua data tersimpan otomatis di perangkat ini (IndexedDB + enkripsi AES-GCM 256) setiap kali ada perubahan. Cadangkan berkala dengan tombol Backup JSON di tab Laporan. Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123; Dapur — dapur / dapur123; Kasir — kasir / kasir123. Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh Warung Kopi Oyen (4 kategori, 12 item menu di tiap outlet, 5 pesanan contoh). Semua perubahan Anda tersimpan di perangkat ini (IndexedDB terenkripsi).

Catatan penting (jujur)

Aplikasi ini menampilkan pesanan di layar dapur dan mencatat statusnya — bukan sistem kasir dengan pembayaran dan bukan sistem produksi restoran sungguhan. Data menu dan pesanan hanya tersimpan di perangkat ini — sekarang di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256). Jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Data tidak tersinkron ke perangkat lain dan tidak ada backup cloud otomatis — pakai tombol Backup JSON di tab Laporan secara berkala. Untuk dipakai bersama oleh kasir dan dapur di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut. Aplikasi ini cocok dipasangkan dengan Restaurant POS kami.
