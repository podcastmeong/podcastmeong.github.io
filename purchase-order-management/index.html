Panduan Penggunaan

Cara memakai Purchase Order Management, harga, dan garansi.

Cara memakai

  1. Tambahkan Supplier di tab Supplier: nama perusahaan, kontak, nomor HP, dan kategori barangnya.
  2. Di tab Purchase Order, buat PO baru: pilih supplier, isi tanggal, lalu tambahkan barang yang dipesan beserta jumlah dan harga satuannya — total dihitung otomatis. PO baru berstatus Draf.
  3. Periksa kembali PO Draf. Bila sudah benar, tekan Kirim ke Supplier — status berubah menjadi Terkirim.
  4. Saat barang datang, buka tab Penerimaan, pilih PO-nya, dan isi jumlah barang yang benar-benar diterima. Barang boleh diterima sebagian dulu; status PO otomatis menjadi Diterima Sebagian, dan menjadi Selesai bila semua barang sudah diterima.
  5. Lacak posisi semua PO di tab Status, lengkap dengan progres penerimaan barangnya.
  6. Lihat semua PO yang pernah dibuat di tab Riwayat, dan rekap pembelian per bulan di tab Laporan — laporan bisa dicetak atau disimpan sebagai PDF.
  7. Masuk dengan akun Anda (Admin / Gudang / Staf) — akun demo: admin / admin123, gudang / gudang123, staf / staf123. Sesi berlaku selama tab masih terbuka.
  8. Pilih Cabang aktif di tab Purchase Order — PO, supplier, penerimaan, dan statistik mengikuti cabang itu; laporan menampilkan ringkasan semua cabang.
  9. Aksi sensitif (hapus PO, hapus supplier, hapus penerimaan, dan PO di atas Rp10.000.000) tidak langsung jalan — diajukan ke tab Persetujuan dan baru berlaku bila disetujui Admin/Gudang. Semua tercatat di tab Audit Log.
  10. Semua data tersimpan otomatis di perangkat ini (IndexedDB + enkripsi) setiap kali ada perubahan. Cadangkan berkala dengan tombol Backup JSON di tab Laporan.

Catatan penting (jujur)

Aplikasi ini berupa satu file HTML dan bekerja offline. Data supplier, purchase order, dan penerimaan barang hanya tersimpan di perangkat ini — sekarang di IndexedDB dengan enkripsi WebCrypto (AES-GCM 256). Jujur: kunci enkripsinya juga tersimpan di perangkat yang sama (demo), jadi ini bukan enkripsi tingkat enterprise sungguhan; jangan simpan data sensitif. Data tidak tersinkron ke perangkat lain dan tidak ada backup cloud otomatis — pakai tombol Backup JSON di tab Laporan secara berkala. Aplikasi ini BUKAN .exe native — dibuka lewat browser di laptop atau HP. Aplikasi ini punya tiga peran pengguna (Admin, Gudang, Staf) di perangkat ini. Untuk pemakaian bersama oleh banyak staf di perangkat berbeda (multi-user lintas perangkat) serta penyimpanan permanen di server dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.

Tombol "Kirim ke Supplier" dalam demo ini hanya mengubah status PO dari Draf menjadi Terkirim di dalam aplikasi — bukan mengirim email atau surat sungguhan ke supplier. Untuk benar-benar menyampaikan PO ke supplier, salin atau cetak rincian PO dari aplikasi ini lalu kirimkan sendiri lewat WhatsApp atau email.
