Panduan

Cara memakai Aplikasi Project Management, harga, dan garansi.

Cara memakai

  1. Masuk sebagai Admin untuk mengatur semua data termasuk pengguna; sebagai Manajer untuk membuat proyek dan tugas, menugaskan ke anggota tim, dan membuka laporan; atau sebagai Anggota untuk mengerjakan tugas yang ditugaskan ke Anda dan memberi komentar.
  2. Di tab Proyek, buat proyek baru dengan tanggal mulai dan tenggat. Progres proyek dihitung otomatis dari tugas-tugasnya (tugas Selesai dibagi total tugas proyek).
  3. Di tab Tugas, buat tugas baru: pilih proyek, anggota yang ditugaskan, tenggat, dan prioritas. Klik Detail & Komentar pada tugas untuk mengubah status, melihat komentar, dan menambahkan komentar baru.
  4. Di tab Tim, lihat beban kerja setiap anggota (jumlah tugas aktif) dan tambah anggota baru bila tim bertambah.
  5. Di tab Tenggat, pantau tugas yang terlambat, jatuh tempo hari ini, dan agenda 7 hari ke depan. Di tab Progres, lihat capaian setiap proyek dan anggota.
  6. Di tab Laporan, pilih periode lalu gunakan Ekspor CSV dan Backup JSON untuk arsip. Data contoh bisa dikembalikan dari kartu Data contoh di bawah.
  7. Semua data tersimpan di perangkat ini (localStorage). Bila ganti perangkat, data tidak ikut — itu batas aplikasi satu file HTML ini.

Akun demo (untuk mencoba): Admin — admin / admin123 (semua akses, termasuk kelola pengguna); Manajer — manajer / manajer123 (proyek, tugas, tim, laporan; tidak bisa kelola pengguna); Anggota — anggota / anggota123 (hanya tugas yang ditugaskan ke Andi Pratama + komentar). Akun demo hanya untuk mencoba demo ini. Setelah membeli, segera ganti kata sandi dan buat akun sendiri di tab Dasbor.

Data contoh

Aplikasi ini memakai data contoh PM Oyen (5 proyek, 14 tugas, 6 anggota tim, 4 komentar: 5 tugas selesai, 4 berjalan, 5 belum dimulai). Semua perubahan Anda tersimpan di perangkat ini.

Catatan penting (jujur)

Progres proyek dihitung dari tugas yang berstatus Selesai — bukan dari jam kerja atau persentase manual. Aplikasi ini bukan sistem akuntansi dan bukan payment gateway (pembayaran dicatat manual). Data hanya tersimpan di perangkat ini (browser perangkat yang membuka aplikasi) dan tidak tersinkron ke perangkat lain. Untuk dipakai bersama oleh tim di perangkat berbeda (multi-perangkat), dibutuhkan versi server — silakan hubungi kami lewat WhatsApp untuk penawaran versi tersebut.
