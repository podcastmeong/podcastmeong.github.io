Panduan — Kasir Toko

CONTOH DEMO — data contoh Toko Oyen untuk calon pembeli.

Fitur di demo ini

  1. Multi-user / multi-role: Admin (semua fitur), Kasir (kasir + laporan sendiri), Gudang (barang & stok + ekspor). Menu berubah sesuai peran yang masuk.
  2. Dasbor + laporan lengkap: omzet hari ini & 7 hari, produk terlaris, penjualan per cara bayar, penjualan per pengguna, rata-rata per transaksi.
  3. Ekspor data: transaksi dan produk bisa diunduh sebagai CSV; seluruh data bisa diunduh sebagai backup JSON.
  4. Notifikasi dalam aplikasi: lonceng di atas menampilkan peringatan stok menipis dan stok habis.
  5. Audit log lokal: setiap login, transaksi, perubahan stok, dan perubahan pengguna tercatat (siapa, apa, kapan) — hanya Admin yang bisa melihat.
  6. Backup & restore: pulihkan data dari file backup JSON di tab Ekspor & Backup.
  7. Kelola pengguna: Admin bisa menambah pengguna, mengubah peran, dan menonaktifkan akun.
  8. Kasir lengkap: keranjang, diskon %, tunai + kembalian, QRIS, transfer, dan struk belanja.

Batas yang jujur (mohon dibaca sebelum membeli)

Data tersimpan per perangkat di browser (localStorage) — tidak ada sinkron antar-perangkat dan tidak ada server. Satu pengguna di satu perangkat. Backup JSON dipakai untuk memindahkan data. Versi server (sinkron online, multi-cabang, API) tersedia sebagai jasa sistem terpisah.

Cara mencoba

  1. Masuk sebagai admin untuk melihat semua fitur, lalu keluar dan masuk sebagai kasir dan gudang untuk melihat menu yang berbeda.
  2. Di tab Kasir, klik barang, atur diskon, bayar tunai — periksa kembalian dan struk, lalu lihat stok berkurang di tab Barang & Stok.
  3. Buka lonceng Notifikasi — ada peringatan stok Susu UHT dan Tisu Wajah.
  4. Di tab Laporan, periksa omzet, produk terlaris, dan ekspor CSV.
  5. Di tab Audit Log (Admin), lihat catatan aktivitas — lalu buat transaksi baru dan lihat catatannya bertambah.
  6. Di tab Ekspor & Backup, unduh backup JSON, lalu tekan Reset Data Demo dan pulihkan dari file tadi.
